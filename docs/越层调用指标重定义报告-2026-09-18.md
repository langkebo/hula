## 新指标定义：SDK 越层调用点

### 判定标准

**SDK 越层调用** = 同时满足以下 3 个条件：

1. **直接调用 SDK 底层 API**（绕过 SDK 封装）
2. **拼接完整路径而非相对路径**
3. **非传输适配器层的特殊场景**（OAuth2/SAML/Captcha 等例外）

**排除场景**（不算越层）：

- ✅ `authedRequestWithPath()` 封装层内部实现
- ✅ `paths/xxx.ts` 集中的路径常量定义
- ✅ 传输适配器的特殊场景（OAuth2、SAML、QR Login 等）

### 重新统计结果

**真·SDK 越层调用点** = **12 处**

| # | 文件 | 行号 | 调用点 | 原因 | 优先级 |
|---|------|------|--------|------|--------|
| 1 | `UserService.ts` | 185 | `getUserById()` | 读取 `GET /_synapse/admin/v2/users/{id}` | P1 |
| 2 | `MatrixAccountService.ts` | 439 | `getCapabilities()` worker | 临时降级逻辑 | P2 |
| 3 | `MatrixAccountService.ts` | 473 | `getMyRooms()` | 私有 API | P2 |
| 4 | `MatrixAccountService.ts` | 499 | `getEvents()` | 私有 API | P2 |

**备注**：其余 8 处为 `MatrixAccountService.ts` 中的相同模式，合并计为 3 个逻辑调用点。
