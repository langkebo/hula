三、候选深化项 1：AdminFacadeService 门面评估

Speculative — 可不拆

文件

src/services/matrix/admin/AdminFacadeService.ts (1062 行)

问题

v1 标记为"上帝服务"。但实际验证：233 个方法中 172 个是纯委托（return this.xxxService.yyy()），仅 61 个含实际逻辑（权限校验、SDK 获取、请求包装）。这是门面模式而非上帝类。

建议

不必拆分。门面的 1062 行是"宽接口"而非"深逻辑"——删除它不会浓缩复杂度，只会把 172 处调用点改成直接引用子服务，增加耦合。建议：

  • 加 // @facade 注释说明意图
  • 把 61 个含逻辑方法中的"权限校验"抽为 AdminGuard
  • ratchet 脚本加白名单豁免

四、候选深化项 2：as any 类型逃逸治理

Strong — 必须做

文件

72 个文件，513 处 as any（v1: 528，仅减 15）

问题

3 天密集重构中 as any 几乎未动——说明团队优先处理了"结构性债务"而忽略了"类型债务"。513 处决口中，服务边界（matrix/ 子域）最危险：SDK 返回值被 as any 吞掉后，上游所有消费方都失去类型保护。

方案

分批剿灭 + ratchet 锁定：

  1. 按目录分批：services/matrix → stores → components
  2. 每批完成后在 ratchet 基线收紧计数
  3. biome noExplicitAny 从 warn 升 error
  4. SDK 边界处用 src/types/matrix-js-sdk-augmentations.d.ts 补类型

Before — 类型堤坝 513 决口

// services/matrix/room/MatrixSpaceService.ts
async getRooms(): Promise<RoomInfo[]> {
  const res = await this.sdk.spaceApi() as any
  return res.rooms as any  // 上游全部失 type
}

// stores/domains/chat/chat/message.ts
const event = rawEvent as any
event.getContent().body  // 无类型提示，重构危险

After — 类型补全 + ratchet 锁定

// matrix-js-sdk-augmentations.d.ts
interface ISpaceApi {
  getRooms(): Promise<{ rooms: RoomInfo[] }>
}

// services/matrix/room/MatrixSpaceService.ts
async getRooms(): Promise<RoomInfo[]> {
  const res = await this.sdk.spaceApi()
  return res.rooms  // 全链路有类型
}

Worth exploring

问题

Worker 是单文件 850 行的 switch-dispatch 巨型消息处理器。新增功能需在 Worker 内加 case、在 Host 加代理方法、在 types 加消息类型——三处同步修改，locality 差。但当前稳定，不阻塞业务。

七、新发现：Manager 模式迁移（v2 新增亮点）

v1 报告未覆盖。3 天内完成 7 个 Manager 迁移，把 SDK 调用从 Service 内联改为委托给 *Manager 类——Service 变薄，Manager 承载 SDK 细节。

Manager 来源 Service 收益
MediaManagerMatrixMediaService上传/下载/配额统一入口
VoiceManagerMatrixVoiceService语音消息逻辑下沉
SearchManagerMatrixSearchService全文检索 SDK 隔离
ReportingManagerSynapseRustExtensions事件上报收敛

AccountDataManagerAccountDataService房间数据存储统一

架构意义：这是 Service 层的"第二次深化"——第一次（v1 前）是把 SDK 包进 Service，第二次（v2）是把 SDK 细节从 Service 抽进 Manager。Service 现在是"域门面"，Manager 是"SDK 适配器"。符合 codebase-design 的 adapter/seam 词汇。
