## 账户安全设置

### Token 自动刷新

HuLa 现在支持自动刷新登录 Token，确保您的会话不会过期。

**功能特点**:
- ✅ 自动检测 Token 过期时间
- ✅ 在过期前 5 分钟自动刷新
- ✅ 无需手动重新登录
- ✅ 性能监控和错误上报

**使用方法**:
1. 登录后，系统会自动启动 Token 刷新机制
2. 无需任何手动操作
3. 如果刷新失败，系统会提示您重新登录

**性能指标**:
- Token 刷新时间 < 500ms
- 自动刷新成功率 > 99%

## 联系方式管理

### 邮箱绑定

您可以在账户设置中绑定和管理邮箱地址。

**操作步骤**:
1. 打开 **设置** → **账户**
2. 滚动到 **联系方式管理** 区域
3. 点击 **邮箱** 标签
4. 点击 **添加邮箱** 按钮
5. 输入您的邮箱地址
6. 点击 **发送验证邮件**
7. 检查邮箱并点击验证链接

**功能说明**:
- ✅ 支持绑定多个邮箱
- ✅ 邮箱验证状态显示
- ✅ 可随时移除已绑定的邮箱
- ✅ 用于找回密码和账户通知

### 手机号绑定

您也可以绑定手机号码。

**操作步骤**:
1. 打开 **设置** → **账户**
2. 滚动到 **联系方式管理** 区域
3. 点击 **手机** 标签
4. 点击 **添加手机** 按钮
5. 输入您的手机号码
6. 点击 **发送验证短信**
7. 输入收到的验证码

**功能说明**:
- ✅ 支持绑定多个手机号
- ✅ 手机号验证状态显示
- ✅ 可随时移除已绑定的手机号
- ✅ 用于短信通知和双重认证

## 设备管理

### 查看登录设备

您可以在会话设置中查看所有已登录的设备。

**操作步骤**:
1. 打开 **设置** → **会话管理**
2. 查看设备列表
3. 当前设备会显示 **当前设备** 标签

**设备信息**:
- 设备名称
- 最后活跃时间
- IP 地址
- 设备类型

### 设备重命名

您可以为设备设置自定义名称，方便识别。

**操作步骤**:
1. 打开 **设置** → **会话管理**
2. 找到要重命名的设备
3. 点击 **重命名** 按钮
4. 输入新的设备名称（1-50 个字符）
5. 点击 **确定** 保存

**使用场景**:
- 区分多个设备（如"办公室电脑"、"家里笔记本"）
- 识别陌生设备登录
- 管理设备访问权限

### 移除设备

您可以移除不信任或不再使用的设备。

**操作步骤**:
1. 打开 **设置** → **会话管理**
2. 找到要移除的设备
3. 点击 **移除** 按钮
4. 确认移除操作

**注意事项**:
- ⚠️ 移除后，该设备将无法访问您的账户
- ⚠️ 当前设备无法被移除
- ⚠️ 移除操作不可撤销

### 登出所有设备

您可以一次性登出所有其他设备。

**操作步骤**:
1. 打开 **设置** → **会话管理**
2. 点击 **登出所有设备** 按钮
3. 确认操作

**注意事项**:
- ⚠️ 当前设备不会被登出
- ⚠️ 其他所有设备将被强制登出
- ⚠️ 操作不可撤销

## 用户搜索

### 搜索其他用户

您可以通过用户搜索功能找到其他用户。

**操作步骤**:
1. 点击 **搜索用户** 按钮（位置取决于具体界面）
2. 输入用户名或邮箱
3. 系统会实时显示搜索结果（300ms 防抖）
4. 点击 **选择** 按钮选择用户

**搜索范围**:
- 用户名
- 显示名称
- 邮箱地址

**使用场景**:
- 添加好友
- 邀请加入房间
- 发送私信

## 常见问题

### Q1: Token 自动刷新失败怎么办？

**A**: 如果 Token 自动刷新失败，系统会提示您重新登录。请：
1. 检查网络连接
2. 确认服务器正常运行
3. 重新登录账户

### Q2: 为什么无法添加邮箱？

**A**: 可能的原因：
- 邮箱格式不正确
- 邮箱已被其他账户绑定
- 验证邮件发送失败（检查垃圾邮件）

### Q3: 如何识别陌生设备登录？

**A**: 在设备列表中：
- 查看设备名称和 IP 地址
- 检查最后活跃时间
- 如果发现陌生设备，立即移除并修改密码

### Q4: 设备重命名后其他设备能看到吗？

**A**: 设备名称仅用于您自己的设备管理，其他用户无法看到。

### Q5: 搜索用户时为什么找不到？

**A**: 可能的原因：
- 用户不存在
- 用户设置了隐私保护
- 搜索关键词不正确
- 网络连接问题
