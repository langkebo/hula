# 消息页三问题修复总结（2026-08-09）

针对 18:10 日志同时报告的三个独立问题，已逐个定位根因并修复，全部通过测试与类型检查。

## ① 阅读回执重复发送（去重竞态）

**文件**：`src/services/matrix/messaging/MatrixReceiptService.ts`
**根因**：`sendReadReceipt` 原逻辑「先查 `lastSentReceiptEventId` 去重 → `await sendReadReceiptByEventId` → 再写标记」，**检查与写入之间夹了 `await`**。当 `changeRoom` 末尾 `markSessionRead` 与单条已读并发触发同一 eventId 时，两次调用都通过检查、各自 `await` 后双发回执。
**修复**：把去重标记 `set` 移到 `await` **之前同步完成**（原子去重），吞噬并发重复；发送失败时清除占位，允许延迟补发任务重试。
**回归**：新增「并发触发同一事件只发一次」+「发送失败后清除占位允许重试」两例。

## ② 独立聊天窗口（windowChat）永久转圈、无历史消息

**文件**：`src/stores/domains/chat/chat/messageLoading.ts`
**根因**：`changeRoom` 的 window guard（`label !== 'home' && label !== 'mobile-home'`）把独立聊天窗口 `windowChat`（Tauri label = `'message'`，`src/views/windowChat/index.vue` 调 `updateCurrentSessionRoomId`）挡在门外 → `getPageMsg` 永不执行 → `hasLoadedOnce` 永 false → 骨架屏永久转。主窗口上一轮已修，故"转圈"发生在独立窗口上下文。
**修复**：guard 增加放行 `'message'`。独立窗口为独立 store 实例，操作均按 roomId 隔离，安全。
**回归**：`message.test.ts` 把 label 改为可变，新增「label='message' 仍加载消息」断言。

## ③ 消息操作栏图标只有 hover 才显文字（2 个按钮空图标）

**文件**：`src/components/rightBox/renderMessage/MessageActionBar.vue`
**根因**：操作栏用 SVG sprite `<use href="#symbol">`。`public/icon.js` 现有 **541** 个 symbol（"184"记忆已过时），但 `forward` 与 `trash` 两个符号**不存在** → 对应按钮渲染空白、仅 hover 出 tooltip 文字。其余 `smiling-face`/`reply`/`copy` 均存在且用 `currentColor` 正常渲染。
注意：项目 Iconify 仅 `@iconify/vue`、无本地 collection，运行时走 `api.iconify.design` 在线 API，被 Tauri CSP 拦截（离线不可用），故操作栏不能迁 Iconify。
**修复**：`forward` → 映射到已存在的 `share`；`trash` → 映射到已存在的 `delete`（均为 `currentColor`）。不扩充 sprite，仅改引用 ID。
