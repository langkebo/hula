## 二、逐项变更说明

### P2-1 双重断言治理（CQ-01，提交 `e0c8f849`）

**问题**：`as unknown as` 双重类型断言在非测试代码中达 **240 处**，掩盖 SDK 类型契约不一致、运行期类型不安全，SDK 升级/重构易崩且编译器无法发现。

**优化动作**：
1. **建 ratchet 计数器**：`check-ratchet.mjs` 新增 `as_unknown_as`（`pattern = /as\s+unknown\s+as/g`，`includeTests: false`），基线锁定 **101**，随既有机制进入 `check:release` 与 CI。
2. **类型守卫承接热点**：`typeGuard` 增加 `unknownToObject` / `unknownToArray`，热点服务改用类型守卫替代双重断言。
3. **全量降级桥接**：将运行时等价的 `as unknown as T` 收敛为 `as T`（仅消除冗余桥接，不改变运行期语义）。
4. **热点文件下降**：`admin/RoomService.ts` 12→3、`MetadataService` 5→0、`MatrixVoiceService` 4→0、`MatrixWidgetService` 6→0、`MatrixDeviceService` 6→1。

**变更文件**：`scripts/check-ratchet.mjs`、`meta/ratchet-baseline.json`、`src/types/typeGuard` 相关、约 60 个 `src/services/matrix/**` 与 `src/**` 文件。

**前后对比**：

| 非测试 `as unknown as` | 240（报告口径，`grep -v __tests__ \| wc -l`） | **101**（ratchet 计数，非测试）≈ 58% ↓ |

**变更文件**：`src/utils/webCompat.ts`（新增）、`src/utils/__tests__/webCompat.test.ts`（新增）、上述 12 个调用点文件、`meta/file-size-baseline.json`（快照）。

## 三、报告交付项结论（未落地，按保守原则）

> 以下各项涉及**删除生产依赖、跨大版本覆盖、配置类改动、大改造**或**需二次取证**，按用户决策「可验证的先做，其余先报告」「配置类只报告，不改配置」，本轮**不落代码/配置**。

### 3.1 P2-3 依赖治理余项（DP-01/02/07/08、EG-07）

- **DP-01（6 个「零直接引用」生产依赖）**：`content-type`/`events`/`loglevel`/`matrix-events-sdk`/`matrix-widget-api`/`sdp-transform`。结论：**迁移前必须逐项核实其是否为 SDK 运行期必需**（多数为 `matrix-js-sdk` 传递依赖的运行期依赖），**不宜直接删**。建议以 `pnpm why <pkg>` + 运行期冒烟二次确认后处理。
- **DP-02（`overrides` 跨大版本覆盖）**：`uuid@<14 → >=14`、`brace-expansion`、`js-yaml`。结论：属强制跨版本，**须配回归**（uuid v14 API 变更）后方可保留，建议加一条「覆盖项回归清单」。
- **DP-07（Tauri 插件精确/范围混用）**：建议统一精确 pin，因插件与 Rust 版本强绑定。
- **DP-08（前沿版本）**：`vue-router 5`/`TS 6`/`Vite 8`/`vitest 4`/`storybook 10` 属重大版本，建议持续观察生态兼容。
- **EG-07（renovate + dependabot 双配置）**：两套更新机器人并存可能重复 PR；且 `dependabot.yml` 的 reviewers `@龙卷风/core` **语法无效**（非合法 GitHub 团队句柄）。建议**二选一**（推荐保留 renovate）并修正/移除无效 reviewers。

### 3.2 P2-2 兼容目标余项（CP-04）

`tsconfig.json` `target: ES2022` / `lib: ESNext` 与 `build.target`（含 `safari15`）错配：TS 不报缺失，运行时平台支持不足，问题延后到生产。结论与处置建议**并入 P1-6 §四 iOS 二选一**：短期抬 `minimumSystemVersion` 至 15.0 对齐构建目标；若确需覆盖 iOS 13/14，则降 `build.target` 并联合本阶段 `webCompat` 特性检测推进（P2-2 已铺好 `webCompat` 基础设施）。

### 3.3 P2-4 测试门禁条件启用（TS-05）

`vitest.config.ts` 的 storybook project 由 `STORYBOOK_TEST` 环境变量 gate，默认 `pnpm test:run` 不含组件交互测试；**若 CI 未显式设置该变量，则组件交互测试实际未跑**。结论：需在 `quality-gate.yml` 或 `security-performance.yml` 显式引入一条 `STORYBOOK_TEST=1` 的作业（或明确其不进入 CI 的决策），本轮仅报告。

### 3.4 P2-5 安全纵深余项（SC-05/07/09）

- **SC-05（`default.json` 桌面权限面偏宽）**：`windows: ["*"]`、`shell:allow-execute` powershell、devtools 开关、宽 `fs` scope。属 capabilities 配置，按「配置类只报告」，建议逐项收敛到最小必需。
- **SC-07（`HttpClient` 无 host allowlist）**：`getRuntimeAwareFetch()` 无 URL/host 白名单，调用方传任意 URL 即外发。建议加显式 host allowlist（homeserver + 后端域名）。
- **SC-09（pre-commit 过弱）**：P2-7 已将其类型检查改增量（体验），但本地仍无依赖审计拦截；建议在 `lint:staged` 之外按需挂只读审计。

### 3.5 P2-6 可维护性余项（CQ-03/05/06、MT-08/09、AR-06/07）

- **CQ-03（biome 关闭 4 条 a11y 规则）**：`noStaticElementInteractions`/`useKeyWithClickEvents`/`noSvgWithoutTitle`/`useAltText` 全 off。建议**按模块分批开启**（先新目录/新组件），而非一次性全开。
- **CQ-05（样式夹层硬编码色）**：token 未覆盖的 SCSS/naive 源约 135 处（ratchet `hardcoded_color=31` 已卡基线）。建议随主题梳理逐层替换为 `--tjg-*`。
- **CQ-06（`WebVitalsObserver` 模块级可变状态）**：违反 ADR-003「禁止 module-level ref」精神，HMR/多实例有状态泄漏风险，建议改实例化或 store 承载。
- **MT-08（格式化函数重复）**：`formatFileSize/formatDuration/formatDate` 约 50 文件多份实现，建议合并为单一工具并回归。
- **MT-09（桌面/移动双实现成本）**：`src/mobile/**` 与 `src/**` 独立覆盖，规模未量化，建议先量化重复面再评估收敛。
- **AR-06（`AdminFacadeService` 795 行上帝服务）**：聚合 172/233 委托方法，建议按域拆分为 facade + 子服务（可参照 workbench 层样板）。
- **AR-07（服务层粒度 459 个 `.ts`）**：单域文件数偏多（如 `access_token` 流经 4+ service），建议按域做「调用链合并」专项。
