# 前端功能集成缺失审查报告

> 审查日期: 2026-07-16
> 审查范围: 基于 `功能实现清单.md` v21.2 对照实际代码审查（Glob/Grep 实测）
> 审查结论: 服务层（SDK + Service）已 100% 完成封装；UI 集成层 PC 端集成度较高，移动端缺口集中在安全流程与高级功能

## 审查方法

对文档中标记为 ✅ 的每个服务层端点，逐一验证是否有对应的 UI 组件调用该服务。审查覆盖：

1. **PC 端**: `src/views/` + `src/components/`
2. **移动端**: `src/mobile/views/` + `src/mobile/components/`
3. **服务调用链**: `.vue` 文件 -> Service -> SDK

### 状态标记

- ✅ **已集成** — 服务层方法已有 UI 组件调用，且入口完整
- ⚠️ **部分集成** — UI 组件存在但功能不完整或缺少关键入口
- ❌ **未集成** — 服务层已封装但无 UI 组件调用

### 与 v21.2 三维度状态对照

本报告聚焦 **UI 集成** 维度（`功能实现清单.md` v21.2 的三维度之一）。v21.2 的完整三维度定义：

| 维度 | 标记 | 含义 |
| --- | --- | --- |
| 服务封装 | ✅ | matrix-js-sdk Manager + HuLa 服务类均已存在（本报告不再重复，默认为 ✅） |
| UI 集成 | ✅ / ⚠️ / ❌ | 本报告的核心审查维度 |
| 回归验证 | ✅ / 未回归 | 有针对性单测/E2E 或真实环境回归记录 |

> 本报告未覆盖"回归验证"维度（该维度在 `功能实现清单.md` 问题台账中单独记录，共 11 项 T-01~T-11）。

## 六、关键发现

1. **服务层 100% 完成**: 所有 API 契约端点均已有 SDK 封装 + 前端 Service 层集成，文档与代码一致。

2. **PC 端 UI 集成度更高**: 此前 v1.0 报告有 4 项误判——经 Glob/Grep 实测交叉核验，`DehydratedDeviceManager.vue`（脱水设备）、`FriendListView.vue`（特殊好友）、`AnnouncementPanel.vue` + `announWindow/index.vue`（公告编辑）、`WorkbenchSearchPane.vue` + `SpotlightDialog.vue`（消息搜索）均已存在且正确接入服务层。PC 端实际缺失仅 7 项，且集中在高级功能（房间升级、黑名单、粘性事件、房间能力、好友分组、推送规则、VoIP 完善）。

3. **移动端 UI 集成缺口最大**: 21 项缺失中，7 项为 P0 高优先级。经交叉核验，此前报告另有 2 项误判——`friends/index.vue` 已有"特别关心"入口，`NoticeEdit.vue` + `NoticeDetail.vue` 已形成完整公告流程。移动端最关键的缺口仍是设备验证、密钥备份和安全备份的深度 UI——PC 端已有 `DeviceVerifyDialog`/`KeyBackupSetupDialog`/`SecureBackupDialog`，移动端 `EncryptionSettings.vue` 和 `SecuritySettings.vue` 虽然存在但可能缺少完整流程。

4. **共用模式建议**: 移动端 P0 项中的设备验证/密钥备份/安全备份可以直接复用 PC 端的逻辑，只需适配 Vant UI 组件库的视觉风格。

5. **v21.2 三维度联动**: 本报告仅覆盖"UI 集成"维度。`功能实现清单.md` v21.2 的问题台账（T-01~T-11）覆盖了"回归验证"维度的 11 项缺失（含附件加解密测试、E2EE 引导测试、Admin 9 子服务测试、Rendezvous 前端测试、投票 UI、Pusher UI、Beacon 移动端等），两个文档应配合阅读。

## 七、实现建议

### 7.1 P0 项实现路径

```
1. 移动端设备验证 -> 复用 PC 端 DeviceVerifyDialog 逻辑，适配 Vant 组件
2. 移动端密钥备份 -> 扩展 EncryptionSettings.vue 的 setup/restore 流程
3. 移动端安全备份 -> 扩展 SecuritySettings.vue 或创建 MobileSecureBackupDialog
4. 移动端 Reaction -> 在 MessageContainer.vue 长按事件中集成表情选择器
5. VoIP 完善 -> 补充 CallView.vue 来电/去电/挂断/静音全流程
6. SAML/SSO 登录 -> 验证 mobile/login.vue 中 SSO 按钮的 WebView 回调流程
7. 移动端 VoIP -> 完善 rtcCall/index.vue 来电界面
```

### 7.2 技术规范

- 移动端组件使用 Vant UI 库，遵循 `#/` 别名引用
- PC 端组件使用 Naive UI，遵循 `@/` 别名引用
- 所有新增 UI 必须通过 i18n（`$t()`）进行文本绑定
- 深色/浅色主题适配使用 `design-tokens.css` 中的 CSS 变量
- 移动端需适配安全区域（`safe-area-inset-bottom`）
- 新增组件应遵循项目命名规范：PascalCase.vue

### 7.3 测试要求

- 每个新增 UI 组件需补充对应的 `__tests__` 单元测试
- 关键交互流程需补充 E2E 测试
- 移动端需在 Android 和 iOS 模拟器上验证
- PC 端需在 Windows/macOS/Linux 上验证
