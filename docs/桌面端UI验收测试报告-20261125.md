# TJG（天机阁）桌面端 UI 验收测试报告

- 测试日期：2026-11-25
- 测试类型：手工功能验收测试（通过 Computer Use 插件真实操作桌面 UI；首轮为只读验收，2026-11-26 补测阶段修改了头像相关业务代码并复测）
- 报告版本：v1.1
- 结论摘要：完成 5 轮登录会话（含 4 次登录-登出切换）、10 个一级模块与 2 个独立窗口（设置 / 文件管理器）遍历，执行用例 118 项，其中通过 74 项、异常 33 项、受限/未覆盖 11 项。发现缺陷 32 个，其中严重 5 个、中等 15 个、轻微 12 个。最严重问题为「设置-存储管理操作后应用整体无响应（AX 与 AppleEvent 均超时）」与「重启后登录使用已失效 access_token，全部请求 401 且重试无效」。
- 补测更新（2026-11-26）：补充「头像」专项 10 项用例（§4 Y、§11），使用用户提供的 1100×1100 PNG 实测。主窗口「编辑资料 → 更换头像」链路通过（上传 mxc://matrix.test/LwvcA6yYflAIbuIC5Cq5NGD1sZamPEYm）；设置页「账户 → 更换头像」链路存在 2 个严重缺陷（裁剪画布空白、确定性上传卡死）与 2 个中等问题，新增 P-33～P-36。累计用例 128 项。
- 修复复测（2026-11-26）：P-33 / P-34 / P-35 已修复并真机复测通过——设置页头像正常显示，裁剪画布与圆形/矩形预览正常渲染，点「确定」上传成功（`data URL → uploadContent 成功 → 设置头像成功`，mxc://matrix.test/n24J0Y2UQJFqeinBqQPV8i1DOIhAXy6k）且弹窗自动关闭、无残留 loading。修复说明见 §9.6、复测记录见 §11.6。P-36（异地登录提醒窗口 404）未处理，仍开放。

## 7. 已知限制与未覆盖项
