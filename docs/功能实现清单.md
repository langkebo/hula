# HuLa 前端功能实现清单

> 基于 matrix-js-sdk API 契约文档系统性审查
> 审查日期: 2026-04-18
> 版本: v6.0
> 依据: `matrix-js-sdk/docs/api-contract/` 下 18 份核心契约文档

***

## 审查方法

对每个契约文档中定义的后端端点，逐条比对以下三层实现状态：

1. **SDK 封装**: matrix-js-sdk 是否提供对应 Manager/方法
2. **前端服务层**: HuLa `src/services/matrix/` 是否封装调用
3. **UI 集成**: 前端组件是否实际使用（仅标注明显缺失）

状态标记：

- ✅ 已实现 — SDK 封装 + 前端服务层均已集成
- ⚠️ 部分实现 — SDK 已封装但前端服务层未完整集成，或功能有限
- ❌ 未实现 — 后端/SDK 已提供但前端服务层未集成
- ➖ 不适用 — 管理端/内部接口，前端不需要集成
