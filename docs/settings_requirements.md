# HuLa 设置界面需求文档

> **版本**: v3.0 | **更新日期**: 2026-04-18 | **参考**: Element Web 设计规范、功能实现清单 v6.0

---

## 1. 文档概述

### 1.1 目的与范围
本文档定义 HuLa 即时通讯应用设置界面的完整功能需求，确保前端设置功能与后端 Matrix 系统能力匹配，并符合现代 UI/UX 标准。

### 1.2 设计理念
- **清晰性**：设置项分组合理，层次分明
- **一致性**：遵循 Element Web 设计规范
- **安全性**：敏感操作二次确认
- **可访问性**：支持键盘导航和屏幕阅读器

### 1.3 Element Web 设计理念对照

**1.3.1 核心设计原则**

| 设计原则 | Element Web 实现 | HuLa 实现方案 |
|---------|-----------------|---------------|
| 视觉层次 | 使用左侧固定标签导航，内容区右侧 | 采用相同布局，标签宽度 220px |
| 信息密度 | 紧凑但不拥挤，保持呼吸感 | 参考 Element，分组间距 24px |
| 状态反馈 | 所有操作即时反馈，loading 状态明确 | 使用 Naive UI Spin/Skeleton |
| 错误处理 | Toast 提示错误，操作可撤销 | 实现全局 Error Toast 机制 |

**1.3.2 交互设计规范**

| 交互模式 | Element Web 做法 | HuLa 实现 |
|---------|-----------------|----------|
| 标签切换 | 即时切换，无loading | 保持 |
| 表单保存 | 自动保存 + 手动保存按钮 | 实现 auto-save + 手动保存 |
| 危险操作 | 红色警告框 + 二次确认 | 红色边框 + N-button confirm |
| 设置搜索 | Ctrl+K 全局搜索 | 实现相同快捷键 |

**1.3.3 响应式设计**

| 断点 | Element Web | HuLa Desktop |
|-----|------------|--------------|
| >= 1200px | 完整侧边导航 | 完整侧边导航 |
| 768-1199px | 收起侧边导航 | 收起侧边导航 |
| < 768px | 底部标签导航 | 不考虑移动端 |

**1.3.4 无障碍设计 (A11Y)**

| 特性 | 实现要求 |
|-----|--------|
| 键盘导航 | 所有可交互元素可 Tab 聚焦 |
| ARIA 标签 | 图标按钮必须添加 aria-label |
| 屏幕阅读器 | 状态变化使用 aria-live 通知 |
| 对比度 | 文本对比度 >= 4.5:1 |
| 焦点指示 | 自定义焦点样式，清晰可见 |

### 1.4 技术栈
| 层级 | 技术 |
|-----|-----|
| 框架 | Vue 3 + TypeScript |
| 状态管理 | Pinia |
| UI 组件 | Naive UI |
| 桌面框架 | Tauri |
| 构建工具 | Vite |

### 3.1 账户设置 (Account)

**功能描述**：管理用户个人资料和账户信息

#### 3.1.1 个人资料

| 字段 | 类型 | 必填 | 验证规则 | 说明 |
|-----|------|-----|---------|-----|
| displayname | string | 否 | 1-50字符 | 昵称 |
| avatar_url | string | 否 | URL格式 | 头像 URL |
| about | string | 否 | 0-500字符 | 个人简介 |

**API 对接**：

| 操作 | API | 方法 | 请求体 |
|-----|-----|------|-------|
| 获取资料 | `/_matrix/client/v3/profile/{user_id}` | GET | - |
| 更新资料 | `/_matrix/client/v3/profile/{user_id}` | PUT | `{displayname, about, avatar_url}` |
| 上传头像 | `/_matrix/media/v3/upload` | POST | `multipart/form-data` |
| 删除头像 | `/_matrix/client/v3/profile/{user_id}/avatar_url` | DELETE | - |

#### 3.1.2 账户管理

| 字段 | 类型 | 说明 |
|-----|------|-----|
| user_id | string | 用户 ID（只读） |
| email | string | 绑定邮箱（若已绑定） |
| phone | string | 绑定电话（若已绑定） |
| creation_ts | number | 账户创建时间 |

**API 对接**：

| 操作 | API | 方法 | 说明 |
|-----|-----|------|------|
| 修改密码 | `/_matrix/client/v3/account/password` | POST | 需要验证原密码 |
| 注销账户 | `/_matrix/client/v3/account/deactivate` | POST | 需要密码确认 |

### 3.2 会话管理 (Sessions)

**功能描述**：管理当前和历史登录设备

#### 3.2.1 当前设备

| 字段 | 类型 | 说明 |
|-----|------|-----|
| device_id | string | 设备唯一 ID |
| display_name | string | 设备名称 |
| last_seen_ts | number | 最后活跃时间 |
| last_seen_ip | string | 最后登录 IP |
| is_current | boolean | 是否为当前设备 |

**API 对接**：

| 操作 | API | 方法 |
|-----|-----|------|
| 获取设备列表 | `/_matrix/client/v3/devices` | GET |
| 获取单个设备 | `/_matrix/client/v3/devices/{device_id}` | GET |
| 更新设备 | `/_matrix/client/v3/devices/{device_id}` | PUT |
| 删除设备 | `/_matrix/client/v3/devices/{device_id}` | DELETE |

#### 3.2.2 设备信任

| 字段 | 类型 | 说明 |
|-----|------|-----|
| device_trust | string | `verified` \| `unverified` \| `blocked` |
| cross_signing_status | boolean | 交叉签名状态 |

**API 对接**：

| 操作 | API | 方法 |
|-----|-----|------|
| 验证设备 | `/_matrix/client/v3/verification/verify` | POST |
| 获取信任状态 | `/_matrix/client/v3/device/{device_id}/trust` | GET |

### 3.4 通知设置 (Notifications)

**功能描述**：配置推送和通知行为

#### 3.4.1 通知渠道

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|-------|-----|
| enable_push | boolean | true | 启用推送 |
| enable_email | boolean | false | 启用邮件通知 |
| noisy_notification | boolean | true | 有声音通知 |

**API 对接**：

| 操作 | API | 方法 |
|-----|-----|------|
| 获取推送配置 | `/_matrix/client/v3/pushers` | GET |
| 设置推送 | `/_matrix/client/v3/pushers/set` | POST |

#### 3.4.2 通知内容

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|-------|-----|
| show_content | boolean | true | 显示消息内容 |
| show_sender | boolean | true | 显示发送者 |
| highlight_words | string[] | [] | 高亮关键词 |

#### 3.4.3 线程通知

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|-------|-----|
| thread_reply_notify | boolean | true | 线程回复通知 |
| thread_participate_notify | boolean | true | 参与的线程有新消息时通知 |
| thread_mention_notify | boolean | true | 线程中被 @提及时通知 |

**API 对接**：

| 操作 | API | 方法 | 说明 |
|-----|-----|------|------|
| 获取未读线程 | `/_matrix/client/v1/threads/unread` | GET | 通过 ThreadingManager |
| 标记线程已读 | `/_matrix/client/v1/rooms/{rid}/threads/{tid}/read` | POST | 通过 ThreadingManager |

#### 3.4.4 空间通知

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|-------|-----|
| space_new_room_notify | boolean | true | 空间新增房间时通知 |
| space_member_change_notify | boolean | false | 空间成员变更时通知 |

#### 3.4.5 好友请求通知

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|-------|-----|
| friend_request_notify | boolean | true | 收到好友请求时通知 |
| friend_accept_notify | boolean | true | 好友请求被接受时通知 |

**API 对接**：

| 操作 | API | 方法 | 说明 |
|-----|-----|------|------|
| 获取收到的好友请求 | `/_matrix/client/v1/friends/request/received` | GET | 通过 FriendManager |
| 获取发出的好友请求 | `/_matrix/client/v1/friends/requests/outgoing` | GET | 通过 FriendManager |

#### 3.4.6 房间通知规则

| 字段 | 类型 | 说明 |
|-----|------|-----|
| room_id | string | 房间 ID |
| rule_type | string | `all_messages`/`mentions_only`/`messages_except_loud`/`none` |
| is_default | boolean | 是否为默认规则 |

**API 对接**：

| 操作 | API | 方法 | 请求体/参数 |
|-----|-----|------|-------------|
| 获取所有规则 | `/_matrix/client/v3/pushrules/` | GET | - |
| 获取房间规则 | `/_matrix/client/v3/pushrules/global/room/{rule_id}` | GET | - |
| 创建房间规则 | `/_matrix/client/v3/pushrules/global/room/{rule_id}` | PUT | `{actions, conditions, pattern}` |
| 更新房间规则 | `/_matrix/client/v3/pushrules/global/room/{rule_id}` | PUT | `{actions, conditions, pattern}` |
| 删除房间规则 | `/_matrix/client/v3/pushrules/global/room/{rule_id}` | DELETE | - |

**规则条件（Conditions）**：

| 条件类型 | 字段 | 说明 |
|---------|------|-----|
| `roomMentionsOnly` | - | 仅房间 @提及 |
| `senderNotificationsPermission` | `key` | 发送者有通知权限时触发 |
| `eventMatch` | `key`, `pattern` | 事件匹配关键词 |
| `profile_tag` | `profile_tag` | 匹配指定 profile tag |

### 3.9 安全与隐私 (Security & Privacy)

**功能描述**：账户安全、隐私设置和屏蔽管理。提供用户对个人信息和交互行为的完全控制。

#### 3.9.1 隐私控制

| 字段 | 类型 | 默认值 | 说明 |

| show_online_status | boolean | true | 显示在线状态 |
| show_typing_status | boolean | true | 显示输入状态 |
| share_read_receipts | boolean | true | 发送已读回执 |
| allow_public_room_discovery | boolean | false | 允许发现公共房间 |
| allow_3pid_discovery | boolean | false | 允许通过邮箱/手机号搜索 |
| sync_presence | boolean | true | 同步其他用户在线状态 |

**API 对接**：

| 操作 | API | 方法 | 存储位置 |

#### 3.9.2 忽略/屏蔽用户

| 字段 | 类型 | 说明 |
|-----|------|-----|
| ignored_users | string[] | 被忽略用户列表（消息不通知） |
| blocked_users | string[] | 被屏蔽用户列表（完全阻止） |

**API 对接**：

| 操作 | API | 方法 |
|-----|-----|------|
| 获取忽略列表 | `/_matrix/client/v3/account_data/m.ignored_user_list` | GET |
| 更新忽略列表 | `/_matrix/client/v3/account_data/m.ignored_user_list` | PUT |

**忽略与屏蔽的区别**：

| 行为 | 忽略 | 屏蔽 |
|-----|-----|-----|
| 接收消息 | ✓ 接收但不通知 | ✗ 完全不接收 |
| 消息历史 | 保留 | 保留（对方可见已发送） |
| 重新添加 | 可取消忽略 | 可取消屏蔽 |
| 对方感知 | 不知道被忽略 | 可能感知（取决于实现） |

#### 3.9.5 账户注销流程

**注销前检查项**：

| 检查项 | 说明 |
|-----|-----|
| E2EE 密钥备份 | 确认已备份所有加密密钥 |
| 设备数据 | 确认重要数据已迁移 |
| 订阅服务 | 确认无未取消的付费服务 |

**注销流程**：

1. 用户点击"注销账户"
2. 显示注销确认对话框，包含风险提示
3. 用户输入密码进行身份验证
4. 系统检查是否有未备份的 E2EE 密钥
5. 若有未备份密钥，提示用户先备份
6. 用户勾选"我理解注销后果"
7. 最终确认注销
8. 执行账户注销 API

**API 对接**：

| 操作 | API | 方法 |
|-----|-----|------|
| 注销账户 | `/_matrix/client/v3/account/deactivate` | POST |

**请求体**：

```json
{
  "auth": {
    "type": "m.login.password",
    "password": "用户密码"
  },
  "erase_account": true
}
```
