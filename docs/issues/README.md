## 2. 使用方式

1. 打开对应任务草稿文件。
2. 补充 `负责人`、`目标版本`、`起止时间`、`Issue 编号`。
3. 将正文复制到实际的 Issue 系统。
4. 在完成建单后，回填真实链接到 `issue-backlog.md` 或项目看板。
