## 三、问题清单（按严重度）

### 🔴 严重 (Critical)

#### C-1: 管理员功能在浏览器 dev 模式下完全不可用

| 项 | 值 |
|----|-----|
| 影响角色 | admin1, superadmin |
| 影响范围 | 所有管理员界面（用户管理、房间管理、注册令牌、媒体、安全/联邦、遥测、举报、外部服务、后台更新、事件举报） |
| 复现步骤 | 1. 浏览器访问 http://localhost:6130/ 并登录 admin1/Admin@123; 2. 主界面加载后观察控制台; 3. 尝试访问 /admin 路由 → 跳转 /404 |
| 预期结果 | 管理员可见管理后台入口，可访问管理功能 |
| 实际结果 | 控制台报 `ADMIN_PERMISSION_DENIED` + `Tauri runtime not available`；/admin → 404；所有管理路由被守卫拒绝 |
| 控制台输出 | `ADMIN_PERMISSION_DENIED`; `Tauri runtime not available`; `前后端管理员验证结果不一致: backend=false, frontend=true` |

**根因分析**（见 [src/stores/domains/admin/admin.ts:76-97](file:///Users/ljf/Desktop/hu_ts/hula/src/stores/domains/admin/admin.ts#L76-L97)）:

```typescript
// admin.ts 双重校验逻辑
const backendResult = await checkAdminViaBackend()    // 调用 TauriCommand.CHECK_ADMIN_STATUS
const frontendResult = await checkAdminViaFrontend()  // 调用 adminService.getUser(userId).admin
isAdmin.value = backendResult && frontendResult

if (backendResult !== frontendResult) {
  logger.warn(`前后端管理员验证结果不一致`)
  isAdmin.value = false   // ← 不一致时强制设为 false
}
```

- `checkAdminViaBackend()` 调用 `invokeWithResult(TauriCommand.CHECK_ADMIN_STATUS, ...)`，依赖 `__TAURA__.invoke`
- 浏览器 dev 模式下 `__TAURI__` 不存在 → 抛异常 → catch 返回 `false`
- `checkAdminViaFrontend()` 调用 admin API → 后端 admin=true → 返回 `true`
- 前后端不一致 → `isAdmin` 被强制设为 `false` → 所有管理路由守卫拒绝

**建议修复**:
- 浏览器 dev 模式下（检测 `!window.__TAURI__`）跳过 Tauri 后端校验，仅用前端校验
- 或将 `checkAdminViaBackend` 在 Tauri 不可用时返回 `true`（类似 `adminApiAvailable=false` 时的跳过逻辑）

## 八、测试限制

1. **浏览器 dev 模式限制**: 本次测试使用 `pnpm dev`（浏览器 dev 模式），非 Tauri 桌面运行时。所有依赖 Tauri 的功能（管理员校验、原生通知、系统托盘、自动启动等）无法在此模式验证。建议补充 Tauri 桌面模式（`pnpm tauri:dev`）的回归测试。
2. **管理后台无法测试**: 由于 C-1 根因，管理员/超级管理员的管理功能（用户管理、房间管理等 10 项）无法在浏览器模式验证。需在 Tauri 桌面模式下重新测试。
3. **browser_use 步骤预算**: 自动化浏览器代理有 60 步预算限制，部分全界面走查被截断为关键路径验证。test2/superadmin 的走查为快速验证而非全量走查。
4. **好友流程**: test1↔test2 好友关系预存，未实际验证"发送请求→接受"完整流程。如需验证，需先解除好友关系。

## 九、结论

本次测试覆盖 4 个账号（2 普通 + 2 管理员）的登录与主界面功能验证。**普通用户核心功能（聊天、好友、设置）基本可用**，存在若干非阻塞性 UI 问题。**管理员功能在浏览器 dev 模式下完全不可用**（C-1），根因为管理员校验逻辑对 Tauri 运行时的硬依赖，建议优先修复。

测试发现 **2 项严重问题**、**4 项中等问题**、**3 项轻微问题**，详见第三节问题清单。
