## 四、发现的问题

### C-1 [严重] 页面刷新/直接导航时强制回退到 /message

**状态**: 已修复

**严重程度**: 严重 (Critical)

**描述**:  
当用户在非 /message 路由（如 /friend、/room、/space）上刷新页面或直接通过 URL 访问时，页面会强制跳转回 /message，导致无法直接访问好友、房间、空间等页面。

**根因**:  
`src/layout/left/hook.ts` 的 `leftHook` composable 在 `onMounted` 中无条件调用 `pageJumps(activeUrl.value)`，而 `activeUrl` 的默认值是 `'message'`。当 layout 组件因页面刷新而重新挂载时，`onMounted` 触发 `router.push('/message')`，覆盖了用户当前的路由。

**问题代码** (`src/layout/left/hook.ts` 第 207 行，修复前):
```typescript
onMounted(async () => {
  /** 页面加载的时候默认显示消息列表 */
  pageJumps(activeUrl.value)  // 无条件跳转到 /message
  ...
})
```

**修复方案**:  
在 `onMounted` 中检查当前路由：如果已在工作台路由（/message、/friend、/room、/space、/search），仅更新 `activeUrl` 高亮状态而不跳转；否则才跳转到默认的消息列表。

**修复代码** (`src/layout/left/hook.ts` 第 205-227 行):
```typescript
const pathToWorkbenchUrl = (path: string): string | null => {
  if (path.startsWith('/message')) return 'message'
  if (path.startsWith('/friend')) return 'friendsList'
  if (path.startsWith('/room')) return 'roomList'
  if (path.startsWith('/space')) return 'space'
  if (path.startsWith('/search')) return 'search'
  return null
}

onMounted(async () => {
  const currentPath = router.currentRoute.value.path
  const workbenchUrl = pathToWorkbenchUrl(currentPath)
  if (workbenchUrl) {
    activeUrl.value = workbenchUrl
  } else {
    pageJumps(activeUrl.value)
  }
  ...
})
```

**验证结果**:  
修复后直接导航到 /friend、/room、/space 均能正常渲染，URL 保持不变。
