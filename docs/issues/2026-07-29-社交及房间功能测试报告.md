## 四、问题列表

### 严重问题（已修复）

#### C-1: KeepAlive + 异步组件切换错误
- **严重程度**: 严重
- **状态**: 已修复
- **组件位置**: [src/layout/center/index.vue](file:///Users/ljf/Desktop/hu_ts/hula/src/layout/center/index.vue) 第 35-38 行
- **问题描述**: `<keep-alive>` 包裹 `<router-view>` 提供的异步组件时，从 Message 组件切换到 FriendsList 组件触发 `parentComponent.ctx.deactivate is not a function` 错误，导致中间栏无法从消息列表切换到好友列表。
- **复现步骤**:
  1. 登录系统后进入消息列表（/message）
  2. 点击左侧导航栏好友列表按钮
  3. URL 变为 /friend 但中间栏仍显示消息列表
  4. 控制台报错：`parentComponent.ctx.deactivate is not a function`
- **预期结果**: 中间栏从消息列表切换到好友列表
- **实际结果**: 中间栏停留在消息列表，组件切换失败
- **修复方案**: 移除 `<keep-alive>` 包裹，直接使用 `<component :is="Component" v-if="Component" />`（与之前 N-2 修复 AsyncRight 的方式一致）
- **修复文件**: [src/layout/center/index.vue](file:///Users/ljf/Desktop/hu_ts/hula/src/layout/center/index.vue#L33-L38)

#### C-2: leftHook 多实例状态不同步
- **严重程度**: 严重
- **状态**: 已修复
- **组件位置**: [src/layout/left/hook.ts](file:///Users/ljf/Desktop/hu_ts/hula/src/layout/left/hook.ts)
- **问题描述**: `leftHook()` 函数被 ActionList、LeftAvatar、InfoEdit、InfoPopover 四个组件分别调用，每次调用都创建独立的状态实例（`activeUrl`、`pageJumps` 等）和 `onMounted` 回调，导致：
  - 状态不同步（各组件的 `activeUrl` 独立维护）
  - 重复调用 `pageJumps('message')` 初始化路由
  - 重复注册 `window.addEventListener('click', closeMenu, true)` 事件监听器
  - 重复注册 `useMitt.on` 事件
- **修复方案**: 将 `leftHook` 改为单例模式，通过模块级 `instance` 变量和 `lifecycleRegistered` 标志确保状态共享和生命周期钩子只注册一次
- **修复文件**: [src/layout/left/hook.ts](file:///Users/ljf/Desktop/hu_ts/hula/src/layout/left/hook.ts)

### 中等问题（待验证）

#### M-1: 消息输入框输入时跳转搜索页
- **严重程度**: 中等
- **状态**: 待验证
- **组件位置**: 消息界面输入框（ChatFooter / MsgInput 组件）
- **问题描述**: 在消息页面输入文字"测试消息123"后，页面自动跳转到搜索页
- **复现步骤**:
  1. 登录 test1 账号
  2. 进入消息列表，点击一个会话
  3. 在输入框中输入文字
  4. 页面跳转到搜索页
- **预期结果**: 文字正常输入到消息输入框
- **实际结果**: 页面跳转到搜索页
- **可能原因**: 浏览器自动化工具可能在输入时触发了 Ctrl+F 快捷键（项目配置了 Ctrl+F 聚焦搜索框），需人工验证是否为应用本身 bug
- **建议**: 人工键盘输入验证，排除自动化工具干扰

#### M-2: 设置页面入口不明确
- **严重程度**: 中等
- **状态**: 待验证
- **组件位置**: 左下角用户头像浮层（InfoPopover 组件）
- **问题描述**: 点击左下角头像后弹出个人信息浮层，但浮层中未找到"设置"入口
- **复现步骤**:
  1. 登录任意账号
  2. 点击左下角用户头像
  3. 查看弹出的浮层内容
- **预期结果**: 浮层中有"设置"入口
- **实际结果**: 浮层中未出现"设置"按钮
- **可能原因**: 设置入口可能位于其他位置（如右上角、系统菜单），或浮层需要滚动查看更多选项
- **建议**: 检查 InfoPopover 组件的设置入口配置

### 轻微问题

#### L-1: 登录按钮 pointer-events: none
- **严重程度**: 轻微
- **状态**: 待验证
- **组件位置**: 登录页面登录按钮
- **问题描述**: 登录按钮在浏览器自动化测试中出现 `pointer-events: none`，无法直接点击
- **可能原因**: 可能是 NaiveUI 按钮在加载状态时设置了 `pointer-events: none`，或 CSS 样式问题
- **建议**: 检查登录按钮的 loading 状态和 CSS 样式
