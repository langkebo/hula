## 四、新发现问题

### 🟠 中等 (Major)

#### N-1: 好友搜索结果与列表不一致
| 项 | 值 |
|----|-----|
| 影响角色 | test2 |
| 复现步骤 | 1. 登录 test2; 2. 进入好友页; 3. 搜索框输入 "test1" |
| 预期结果 | 搜索结果应显示 test1（已是好友） |
| 实际结果 | 搜索显示"未找到匹配的好友"，但清除搜索后 test1 出现在好友列表中 |
| 可能根因 | 搜索过滤逻辑可能匹配字段不完整（如只匹配 name 不匹配 userId），或搜索使用了不同的数据源 |

#### N-2: Vue 组件卸载异常
| 项 | 值 |
|----|-----|
| 影响角色 | 全部 |
| 控制台输出 | `TypeError: parentComponent.ctx.deactivate is not a function` |
| 影响 | 组件卸载时可能产生内存泄漏或 UI 残留 |
| 可能根因 | n-popover 或 n-dropdown 等动态组件在卸载时调用了已销毁的上下文 |

#### N-3: Sync 请求中断
| 项 | 值 |
|----|-----|
| 影响角色 | 全部 |
| 控制台输出 | `ApiError: RoomManager.POST /sync failed` / `net::ERR_ABORTED` |
| 影响 | 同步中断可能导致消息延迟，但页面切换时属正常行为 |

### 🟡 轻微 (Minor)

#### N-4: MaxListenersExceededWarning
| 项 | 值 |
|----|-----|
| 控制台输出 | `MaxListenersExceededWarning: Possible EventEmitter memory leak` |
| 影响 | 事件监听器未正确清理，长期运行可能内存泄漏 |
