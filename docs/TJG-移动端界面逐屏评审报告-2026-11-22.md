## 二、评审输入与限制（必读）

1. **本次为代码级评审**：所有结论来自源码静态分析，可精确判定"尺寸声明、状态分支、路由引用、handler 是否为空"。
2. **无法从代码判定的维度**（需真机截图，见第七节）：实际对比度比值（WCAG 4.5:1 / 3:1）、视觉重心对齐、留白胆量、图标风格、字重层级、骨架屏与实体形状匹配。**本报告不对这些维度编造结论或比值**。
3. **px→pt 换算已查清**（否则触控判断会全错）：`build/config/vite.config.mobile.ts:26-32` 的 `postcss-pxtorem` 配置 `rootValue: 16, propList: ['*'], minPixelValue: 0`；全仓未找到动态根字号脚本（`src/utils/fontScale.ts:21-23` 只写 `--tjg-font-scale`）。故根字号保持默认 16px，**代码 px 与视觉 CSS px 为 1:1**，可直接与 44pt / 48dp 比较。（注：`propList: ['*']` 走 `matchAll` 分支，**CSS 自定义属性 `--*` 内的 px 同样参与转换**，并非豁免；因根字号固定 16px，换算后与 1:1 结论一致，不影响组件尺寸判断。）
4. **移动端路由与裁剪机制**：移动端路由注册在 `src/router/routes/mobile.ts` 与 `mobileMySettingsRoutes.ts`（**在 `src/router/routes/` 下，不在 `src/mobile/`**）；admin / AI 模块通过**构建期别名替换**移除——`vite.config.ts:48-53` 把 `@/router/entries/platformRoutes` 指向 `src/router/entries/mobileRoutes.ts`，相关路由与入口不进入移动端产物，而非运行时 `isMobile()` 隐藏。

## 四、P1 问题清单（规范违反，先修）

### P1-1 聊天头部"更多"按钮热区偏小
- **位置**：`src/mobile/components/chat-room/HeaderBar.vue:55`
- **问题**：`@click` 直接挂在 `svg` 上，元素声明 `w-24px h-24px p-5px`；外层 `.header-bar__actions`（`:147-150`）只有 `gap: 4px; padding-inline-end: 8px`，无 min 尺寸；实际可点区约 24px（含 padding 视 box-sizing 至多 34px）。模板外层 `:45` 虽写 `gap-8px`，但被 `.header-bar__actions` 的 `gap: 4px` 覆盖，窄屏下两按钮更近。
- **依据**：Apple HIG 触控目标 44×44pt；Material Design 48×48dp（以官方当前版本为准）。
- **严重度**：P1
- **改法**：给 svg 加伪元素扩热区 `after:absolute after:-inset-10px after:content-['']`，或包一层 `min-w-[44px] min-h-[44px] flex items-center justify-center` 的 button。

### P1-2 私密模式切换按钮偏小且紧邻"更多"，存在后果性误触
- **位置**：`src/mobile/components/chat-room/HeaderBar.vue:162-185`（按钮样式 `width/height: 28px`）、`:146-159`（窄屏 `width: 24px`）；与"更多"按钮的实际间距为 `.header-bar__actions` 的 `gap: 4px`（`:147-150`）。
- **问题**：按钮本身 < 44px，且与相邻可点元素仅隔 4px（模板 `:45` 的 `gap-8px` 被覆盖）；该按钮切换会话私密模式（有副作用），误触代价高于普通导航。
- **补充事实**：点击并非"点即切换"——已激活时直接退出；未激活时先弹 `van-dialog` 二次确认（`MobileChatMain.vue:212-225`）。确认框降低了误触的**后果**，但热区与间距问题仍然成立（误触会先弹出确认框，造成打断）。
- **依据**：同上触控目标基线；相邻危险操作应加大隔离（以官方当前版本为准）。
- **严重度**：P1（**真机复核若确认易误触则升 P0**）
- **改法**：视觉可维持 28px，用 `after:-inset-8px` 把热区扩到 44px；将其与"更多"按钮间距增至 ≥16px，或把私密模式收进"更多"菜单，避免顶栏并列两个小按钮。

### P1-3 好友页"添加"按钮无扩热区（同类控件不一致）
- **位置**：`src/mobile/views/friends/index.vue:26-28`
- **问题**：`van-button size="small"` + 16px svg，未加扩热区伪元素；对比消息页同类按钮（`views/message/index.vue:28-35,47-53` 有 `after:-inset-6px`）不一致。
- **依据**：同上触控目标基线；同平台同类控件应一致。
- **严重度**：P1
- **改法**：与消息页对齐，加 `after:absolute after:-inset-6px after:content-['']`，或统一改用 `min-w-[44px] min-h-[44px]` 的图标按钮。

### P1-4 聊天输入"更多面板"操作项热区不足
- **位置**：`src/mobile/components/message/MobileOutboxBar.vue:72-76,103-106`
- **问题**：容器 `min-height: 40px`，内部操作按钮 `min-height: 28px`，均 < 44px。
- **依据**：同上触控目标基线。
- **严重度**：P1
- **改法**：操作按钮 `min-height` 提至 44px，或加 `::after` 扩热区；保持视觉行高不变。

### P1-5 媒体查看器 / 个人资料页返回箭头偏小
- **位置**：`src/mobile/views/chat-room/MediaViewer.vue:4-6`（24px svg，父容器无 min 尺寸）、`src/mobile/views/my/SimpleBio.vue:28`（页头返回图标，32px，父容器无 min 尺寸）；另 `:47-51` 的 24px svg 是资料卡 `#right` 右箭头（同样触发 `router.back()`），一并纳入。
- **问题**：返回类按钮可点区 24–32px，无扩热区处理。对比 `HeaderBar.vue:4` 返回键已用 `min-h-[44px]`，属遗漏。
- **依据**：同上触控目标基线。
- **严重度**：P1
- **改法**：父容器加 `min-w-[44px] min-h-[44px] flex items-center justify-center`，与 HeaderBar 返回键实现对齐。

### P1-6 无网态仅覆盖消息列表一屏
- **位置**：`components/common/MobileConnectionBanner.vue` 仅在 `views/message/index.vue:62` 接入。
- **问题**：8 个关键屏中 7 屏（好友、我的、聊天主屏、房间、空间、公告列表/详情）无页面级无网提示。断网时这些屏无"发生了什么 / 能否重试"的反馈。
  - 例外：聊天主屏有发送失败条 `MobileOutboxBar`（`v-if="failedCount > 0"`），但那是"发送失败"而非"当前离线"提示，不能替代全局无网态。
- **依据**：移动端状态完备性——无网态应反馈网络状态与恢复路径（以官方当前版本为准）。
- **严重度**：P1
- **改法**：把 `MobileConnectionBanner` 提升到 `ChatRoomLayout` / `MobileLayout` 等布局层统一挂载，覆盖所有子屏；保留消息列表现有接入点避免重复。

**P2-4 10px 辅助字号偏小**

- 依据：辅助文字最小字号建议（以官方当前版本为准）；项目自身字号 token 纪律。
- 严重度：P2 ｜ 改法：改用 `var(--tjg-font-size-2xs)`（11px）并纳入 `--tjg-font-scale`；若确需保留 10px，则在 token 中新增 `--tjg-font-size-3xs: calc(10px * var(--tjg-font-scale))` 并登记，同时校正 2xs/xs 的命名顺序。

### 11.1 P1 触控热区（6 处）

#### 11.1.1 通用写法（先记这一条）

扩热区的伪元素有三个必须条件，缺一个就无效：

```html
<!-- 1. 父元素必须是 position: relative，否则 ::after 会相对最近定位祖先定位 -->
<!-- 2. ::after 必须有 content: ''，否则不生成 -->
<!-- 3. 父元素不能有 overflow: hidden，否则扩出去的部分被裁掉 -->
<button class="relative min-w-[44px] min-h-[44px] flex items-center justify-center ...">
  <svg class="w-24px h-24px" aria-hidden="true">...</svg>
</button>
```

**如果是给已有元素补、不想改布局**，用伪元素方案：

```html
<svg class="relative w-24px h-24px after:absolute after:-inset-10px after:content-['']">...</svg>
<!-- 24 + 10*2 = 44px 可点区 -->
```

**注意 `-inset` 的数值要算准**：目标 44px − 元素实际尺寸，除以 2。

| 元素尺寸 | 需要 `-inset` | 计算 |
|---:|---:|---|
| 24px | 10px | (44−24)/2 |
| 28px | 8px | (44−28)/2 |
| 20px | 12px | (44−20)/2 |
