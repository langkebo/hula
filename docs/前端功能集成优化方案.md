## 三、优化原则与技术规范

1. **分层严格遵守**：组件 → Store → Service → SDK，组件层禁止 `import` matrix-js-sdk。
2. **别名规范**：PC 用 `@/`，移动用 `#/`，跨端共享逻辑放 `src/composables/` 或 `src/hooks/`。
3. **UI 库分工**：PC 用 Naive UI，移动用 Vant；新增组件命名 `PascalCase.vue`。
4. **i18n 强制**：所有可见文案经 `$t()` 绑定，新增 key 进 `src/locales/`。
5. **主题适配**：浅/深色用 `design-tokens.css` / `variable.scss` 的 CSS 变量；移动端 `safe-area-inset-bottom`。
6. **无障碍**：图标优先 SVG（遵循用户偏好），关键操作支持键盘。
7. **Worker 边界**：SDK 重操作仍走 `matrixSdk.worker.ts`，UI 仅订阅事件。
8. **错误处理**：Service 内 try-catch，UI 层经 `matrixErrorTranslator.ts` 转译。

## 六、集成接口标准化方案

### 6.1 组件-服务调用契约

统一约定组件调用服务层的三段式结构：

```ts
// 组件内禁止：import { MatrixClient } from 'matrix-js-sdk'
// 组件内必须：经 Service
const service = MatrixVerificationService.getInstance()
try {
  const result = await service.startSasVerification(userId, deviceId)
  // 处理成功
} catch (err) {
  message.error(matrixErrorTranslator.translate(err))
}
```

### 6.2 跨端 Composable 抽取规范

安全/通讯类共享逻辑抽取为 `src/composables/`，命名 `useXxxFlow.ts`：

| Composable | 复用场景 | 输入 | 输出 |
|-----------|---------|------|------|
| `useDeviceVerifyFlow` | PC + 移动设备验证 | userId/deviceId | step、emoji[]、verify()、cancel() |
| `useKeyBackupFlow` | PC + 移动密钥备份 | mode: 'setup'\|'restore' | progress、recoveryKey、submit() |
| `useSecureBackupFlow` | PC + 移动安全备份 | — | phase、create()、restore() |
| `useVoIPCallFlow` | PC + 移动通话 | roomId | state、mute()、video()、hangup() |
| `useReactionFlow` | PC + 移动消息反应 | eventId | reactions、toggle() |

### 6.3 事件订阅标准

UI 通过 `MatrixEventService` 订阅，禁止裸监听 SDK：

```ts
const off = MatrixEventService.on('verification.request', handler)
onUnmounted(off)
```

### 6.4 错误与日志标准

- Service 内 `try-catch`，错误经 `@tauri-apps/plugin-log` 记录
- UI 层错误经 `matrixErrorTranslator.ts` 转译后 `message.error($t(...))`
- 禁止在组件层 `console.error` 吞掉 SDK 异常

### 6.5 类型安全

- 复用 `src/types/matrix-js-sdk-augmentations.d.ts`（不拆分）
- 新增公共类型入 `src/types/`，组件私有类型局部定义
- 提交前 `vue-tsc --noEmit` 零错误
