## 1. 管理员后台界面

### 1.1 入口与权限控制

#### 1.1.1 入口位置

**PC 端**:
- 主界面左侧导航栏底部，设置图标下方
- 使用 🔧 扳手图标（灰色，不显眼）
- 仅当用户角色为 `admin` 时显示
- 点击后跳转至 `/admin` 路由

**移动端**:
- 底部 Tab 栏"我的"页面内
- 折叠在"高级设置"分组中
- 使用 🔧 扳手图标 + "管理后台"文字
- 仅当用户角色为 `admin` 时显示

#### 1.1.2 权限判断

```typescript
// 权限检查逻辑
const isAdmin = computed(() => {
  const userInfo = currentUserStore.getCurrentUserInfo()
  return userInfo?.role === 'admin' || userInfo?.is_admin === true
})
```

**非管理员用户**:
- 完全不显示管理员入口
- 直接访问 `/admin` 路由时重定向到首页
- 显示 Toast: "您没有权限访问此页面"

### 1.3 功能模块详细设计

#### 1.3.1 仪表盘

**后端对应**: `GET /_synapse/admin/v1/statistics`

**PC 端界面**:
- **统计卡片网格**（3 列，间距 24px）:
  - 注册用户数: 大数字 + 较昨日变化百分比（绿色上升/红色下降）
  - 活跃用户数: 同上
  - 房间数: 同上
  - 消息数: 同上
  - 在线设备数: 同上
  - 存储使用量: 进度条 + 百分比

- **图表区域**:
  - 用户增长趋势（折线图，时间范围: 7天/30天/90天）
  - 消息量趋势（柱状图，同上）
  - 活跃时段分布（热力图，24小时 × 7天）

- **系统健康卡片**:
  - CPU 使用率: 环形进度条
  - 内存使用率: 同上
  - 磁盘使用率: 同上
  - 数据库连接池: 数字 + 状态指示灯

**移动端界面**:
- 统计卡片纵向排列（单列）
- 图表支持横向滑动查看
- 系统健康使用垂直进度条

### 2.3 阅后即焚功能

#### 2.3.1 发送方视角

**发送界面**:
- 开启阅后即焚后，消息气泡右上角显示 🔥 火焰图标
- 消息底部显示倒计时（发送后 30 秒）:
  ```
  ┌─────────────────────────────┐
  │  这是一条阅后即焚消息        │
  │                             │
  │  🔥 将在对方阅读后销毁       │
  └─────────────────────────────┘
  ```

**已阅读状态**:
- 对方阅读后，消息变灰 + "将在 30 秒后销毁" 文案
- 倒计时进度条（底部细条，红色）

**销毁后**:
- 消息替换为 "🔥 消息已销毁" 占位
- 占位样式: 半透明 + 斜体 + 灰色文字

#### 2.3.2 接收方视角

**未阅读**:
- 消息气泡显示 🔥 图标
- 提示: "阅后即焚消息 — 阅读后将自动销毁"

**阅读时**:
- 首次进入视口时触发阅读确认
- 显示倒计时: "此消息将在 30 秒后销毁"

**销毁动画**:
- 渐隐效果（300ms）
- 火焰特效（可选）
- 最终显示: "🔥 消息已销毁"

### 2.4 防截屏功能

#### 2.4.1 触发机制

- 当房间标记为私密聊天时，后端发送 `com.hula.privacy` 状态事件
- 前端监听此事件，自动启用防截屏

#### 2.4.2 PC 端实现

**视觉提示**:
- 私密聊天窗口添加水印:
  - 内容: 用户ID + 当前时间
  - 样式: 半透明灰色，45度倾斜，重复平铺
  - 密度: 每 200px 一个水印

**截屏检测**:
- 使用 Tauri API 监听截屏事件（如果平台支持）
- 检测到截屏时:
  1. 向房间发送系统消息: "⚠️ 用户 @xxx 截屏了私密聊天内容"
  2. 显示本地警告 Toast: "截屏行为已被记录"

#### 2.4.2 移动端实现

**Android**:
- 启用 `FLAG_SECURE` 标志
- 阻止系统截屏和录屏

**iOS**:
- 使用 `UIApplication.shared.isIdleTimerDisabled` 配合屏幕录制检测
- 检测到屏幕录制时模糊内容

## 4. 安全与隐私规范

### 4.1 管理员权限验证

```typescript
// 路由守卫
const adminGuard = async (to, from, next) => {
  const userInfo = await matrixAccountService.getCurrentUserInfo()
  if (userInfo?.role !== 'admin') {
    showToast('您没有权限访问此页面', 'error')
    next('/')
  } else {
    next()
  }
}
```

### 4.2 私密聊天安全

- **端到端加密**: 使用 `m.room.encrypted` 事件类型
- **密钥管理**: 自动交换设备密钥
- **消息不留存**: 后端不存储私密聊天消息内容
- **截屏警告**: 截屏行为通知所有群成员

### 4.3 隐私合规

- 私密模式切换需用户明确确认
- 阅后即焚功能需明确告知用户
- 截屏检测需符合当地法律法规
