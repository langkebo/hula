# 房间界面优化方案

> 基于 TJG-prototype.html 原型设计与 4 张界面截图，对比项目现状，制定房间主界面、房间详情抽屉、房间设置抽屉、聊天界面的优化调整方案。
>
> 撰写日期：2026-08-09

---

## 0. 原型 4 张截图解读

### 截图 1 — 房间主界面（卡片网格视图）

- **布局**：顶部标题栏「房间」+ 右侧 Tab（全部 / 我加入的 / 我创建的 / +）
- **工具栏**：搜索框 + 3 个下拉筛选器（所有类型 / 加密不限 / 成员不限）
- **主体**：4 列卡片网格（`grid-template-columns: repeat(auto-fill, minmax(220px, 1fr))`）
- **房间卡片内容**：
  - 顶部：头像（圆角矩形，渐变背景 + 文字首字）+ 房间名 + 图标（联邦/加密/锁定）
  - 副标题：在线人数/总人数（如 `892/2032 人在线`）
  - 描述：1-2 行截断文字
  - 标签行：联邦标签（蓝色）、成员数标签
  - 底部操作栏：4 个图标按钮（消息 / 信息 / 设置 / 置顶）
- **整体风格**：深色主题，卡片背景 `--bg-mid`，圆角 `12px`，hover 上浮 + 边框高亮

### 截图 2 — 房间详情抽屉（点击卡片后右侧滑出）

- **宽度**：约 480px，从右侧滑入，带阴影
- **头部**：标题「房间详情 · TJG 官方频道」+ 关闭按钮
- **Hero 区域**：大头像（64x64 圆角矩形）+ 房间名 + 房间 ID（`!official:tjg.im`）+ 成员/在线统计
- **统计卡片行**：3 列网格 — 总成员（2032）/ 在线（892）/ 公告（0），数字用强调色
- **房间描述**：文本块，深色背景
- **最近消息**：预览最近一条消息（发送者 + 内容截断）
- **核心成员**：列表，带头像 + 角色标签（创建者/管理员/成员）+ 在线状态
- **底部操作栏**：两个按钮 — 「进入房间」（主色，全宽）+ 「房间设置」（次要）

### 截图 3 — 房间设置抽屉（点击「房间设置」后替换详情抽屉）

- **宽度**：约 520px，比详情抽屉略宽
- **头部**：标题「房间设置 · TJG 官方频道」+ 关闭按钮
- **Tab 栏**：基本信息 / 成员 / 权限 / 加密 / 通知 / 别名 / 历史 / 保留 / 标签 / 粘性（横向滚动）
- **基本信息 Tab 内容**：
  - 房间名称（输入框）
  - 主题/描述（textarea）
  - 房间 ID（只读，等宽字体）
  - 成员数（只读，显示 `2032 成员 · 892 在线`）
  - 房间头像（当前头像 + 上传/移除按钮）
- 其他 Tab 内容在截图中未完全展示

### 截图 4 — 聊天界面（点击「进入房间」后跳转）

- **三栏布局**：
  - **左栏（~300px）**：顶部「消息」+ 操作按钮 → 空间快捷入口（TJG 生态 / 开发者空间）→ 会话过滤标签（全部 / 未读(4) / 群聊 / 单人）→ 房间列表（头像 + 名称 + 最后消息 + 时间 + 未读数）
  - **中栏（flex:1）**：聊天头部（房间名 + 在线人数 + 操作图标：菜单/语音/视频/成员/搜索/S/外链/更多）→ 消息时间线（气泡 + 头像 + 时间戳 + 已读状态）→ 输入区（工具栏 + 文本框 + 发送按钮）
  - **右栏（~240px）**：成员列表（在线 8 / 离线 4 分组）+ 房间操作（通知设置 / 置顶会话 / 静音）
- **消息类型**：文本气泡、位置消息、撤回提示、加密失败提示、正在输入指示
- **右侧成员列表**：带头像 + 在线状态点 + 角色图标 + MXID 显示

## 1. 现状与原型差距分析

### 1.1 房间主界面

| 维度 | 原型设计 | 项目现状 | 差距 |
|------|---------|---------|------|
| **布局模式** | 卡片网格（4 列，`minmax(220px,1fr)`） | 垂直列表（`TjgRoomListItem`，单列 58px 行高） | **大** — 需从列表改为卡片网格 |
| **Tab 切换** | 全部 / 我加入的 / 我创建的 / + | 无 Tab，仅工具栏筛选按钮 | **大** — 缺少 membership 维度 Tab |
| **筛选器** | 搜索框 + 3 下拉（类型/加密/成员） | 搜索框 + 参与类型按钮组 + 会话类型按钮组 | **中** — 筛选维度不同，原型用下拉而非按钮组 |
| **卡片内容** | 头像 + 名称 + 在线/总数 + 描述 + 标签 + 4 操作图标 | 头像 + 名称 + 时间 + 最后消息 + 未读数 + 标签 | **大** — 原型显示在线人数和描述，当前显示最后消息和时间 |
| **卡片操作** | 底部 4 图标（消息/信息/设置/置顶） | 右键菜单 + 双击进入 | **中** — 原型有显式操作栏 |
| **空状态** | 网格空状态 | `n-empty` + 聊天图标 | **小** — 基本具备 |

### 1.2 房间详情抽屉

| 维度 | 原型设计 | 项目现状 | 差距 |
|------|---------|---------|------|
| **触发方式** | 单击卡片 → 右侧滑出抽屉（480px） | 单击 → 路由跳转 `/room/:roomId` → `RoomDetailPane`（右侧栏内嵌） | **中** — 当前是路由驱动内嵌面板，原型是独立抽屉滑出 |
| **Hero 区域** | 大头像 64x64 + 名称 + ID + 统计 | 头像 52x52 + 名称 + ID（截断） | **小** — 尺寸和布局略有差异 |
| **统计卡片** | 3 列网格（总成员/在线/公告），数字强调色 | 信息网格（topic/members/online/visibility/encryption），label-value 行 | **中** — 原型用数字卡片，当前用 label-value 行 |
| **最近消息** | 预览最近消息（发送者 + 内容） | 无 | **缺失** |
| **核心成员** | 成员列表（头像 + 角色 + 在线状态） | 无 | **缺失** |
| **底部操作** | 「进入房间」+「房间设置」并排 | 「进入聊天」+「设置」+「邀请」垂直排列 | **中** — 布局不同 |
| **宽度/动画** | 480px，slide-in 动画 + 阴影 | 右侧栏宽度可变（拖拽），无独立滑出动画 | **中** |

### 1.3 房间设置抽屉

| 维度 | 原型设计 | 项目现状 | 差距 |
|------|---------|---------|------|
| **Tab 体系** | 10 个 Tab（基本信息/成员/权限/加密/通知/别名/历史/保留/标签/粘性） | 无 Tab，单一设置表单（名称 + 主题 + 提交/取消） | **大** — 缺少多 Tab 架构和大部分设置项 |
| **宽度** | 520px（比详情抽屉宽） | 复用右侧栏宽度（可拖拽） | **中** |
| **基本信息字段** | 名称/主题/ID/成员数/头像（上传/移除） | 名称/主题（textarea） | **中** — 缺少 ID 展示、成员数、头像管理 |
| **成员管理 Tab** | 成员列表 + 角色操作 | 无 | **缺失** |
| **权限 Tab** | 权限矩阵（power_levels 编辑） | 无 | **缺失** |
| **通知/别名/历史/保留/标签/粘性 Tab** | 各有独立面板 | 无 | **全部缺失** |
| **切换方式** | 详情抽屉 → 点击「房间设置」→ 替换为设置抽屉 | 详情面板内 `settingsMode` 切换 | **中** — 原型是独立抽屉替换 |

### 1.4 聊天界面

| 维度 | 原型设计 | 项目现状 | 差距 |
|------|---------|---------|------|
| **整体布局** | 三栏（左列表 ~300px / 中聊天 flex:1 / 右成员 ~240px） | 两栏（左列表 / 右聊天），成员列表在聊天内右侧栏 | **中** — 布局架构不同 |
| **左栏结构** | 消息标题 + 空间快捷入口 + 会话过滤标签 + 房间列表 | 工具栏（标题 + 搜索 + 筛选）+ 房间列表 | **中** — 缺少空间快捷入口和会话过滤标签 |
| **聊天头部** | 汉堡菜单 + 房间名 + 在线状态 + 7 个操作图标 | `ChatHeaderRoot` + `ChatHeaderToolbar`（已有较多功能） | **小** — 基本具备，图标数量/排列有差异 |
| **消息时间线** | 气泡 + 头像 + 时间戳 + 已读状态 + 加密失败/撤回/位置等 | `ChatMessageList` 已支持多种消息类型 | **小** — 基本具备 |
| **右侧成员面板** | 在线/离线分组 + 头像 + 角色 + MXID + 房间操作 | `ChatSidebar.vue` 已有成员列表 + 在线分组 | **小** — 基本具备 |
| **输入区** | 工具栏 + 文本框 + 发送按钮 | 已有完整输入区 | **小** — 基本具备 |

## 2. 优化任务清单

### P0：房间主界面卡片化重构

#### P0-1：房间卡片网格布局

- **现状**：`RoomList.vue` 使用 `RoomSessionList` → `TjgRoomListItem` 垂直列表，行高 58px
- **目标**：改为卡片网格布局，4 列自适应（`minmax(220px, 1fr)`），卡片包含头像/名称/在线人数/描述/标签/操作栏
- **涉及文件**：
  - 新建：`src/components/room/RoomCardGrid.vue`（卡片网格容器）
  - 修改：`src/views/homeWindow/RoomList.vue`（替换 `RoomSessionList` 为 `RoomCardGrid`）
  - 修改：`src/components/room/RoomCard.vue`（已有，需扩展显示在线人数、描述、操作栏）
- **实施要点**：
  - 复用已有 `RoomCard.vue`，补充：在线人数显示、描述文字（2 行截断）、底部 4 图标操作栏
  - 网格容器使用 CSS Grid：`grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); gap: 14px`
  - 卡片 hover 效果：`translateY(-2px)` + 边框高亮
  - 单击卡片 → 打开房间详情抽屉；双击 → 进入聊天
- **验收**：房间列表以卡片网格展示；hover 有上浮效果；单击/双击行为正确

#### P0-2：房间列表 Tab 切换

- **现状**：无 Tab，仅工具栏筛选按钮
- **目标**：顶部增加 Tab 栏（全部 / 我加入的 / 我创建的），按 membership 过滤
- **涉及文件**：
  - 修改：`src/views/homeWindow/RoomList.vue`（添加 Tab 组件）
  - 修改：`src/composables/workbench/useMessageSessionFilters.ts`（新增 membership 过滤维度）
- **实施要点**：
  - Tab 组件使用分段按钮样式（原型中 `seg-tabs` 样式）
  - 「全部」= 所有房间；「我加入的」= `membership === 'join'`；「我创建的」= 当前用户为 creator
  - Tab 切换时更新过滤条件，与搜索/筛选器联动
- **验收**：3 个 Tab 正确过滤房间列表；与搜索关键词联动

#### P0-3：房间卡片操作栏

- **现状**：右键菜单 + 双击进入
- **目标**：卡片底部增加 4 个图标按钮（消息 / 信息 / 设置 / 置顶）
- **涉及文件**：
  - 修改：`src/components/room/RoomCard.vue`（添加底部操作栏）
- **实施要点**：
  - 消息按钮 → 进入聊天（`router.push({ name: 'message', params: { roomId } })`）
  - 信息按钮 → 打开房间详情抽屉
  - 设置按钮 → 打开房间设置抽屉
  - 置顶按钮 → toggle pinned 状态
  - 图标使用 SVG `<use>` 引用，线宽 1.5px
- **验收**：4 个按钮功能正确；图标样式符合设计规范

### P1：房间详情抽屉重构

#### P1-1：独立抽屉滑出组件

- **现状**：`RoomDetailPane.vue` 作为右侧栏内嵌面板，路由驱动
- **目标**：新建独立抽屉组件，从右侧滑出（480px），覆盖在房间列表之上
- **涉及文件**：
  - 新建：`src/components/room/RoomDetailDrawer.vue`
  - 修改：`src/views/homeWindow/RoomList.vue`（集成抽屉）
- **实施要点**：
  - 抽屉宽度 480px，`position: absolute; right: 0; top: 0; bottom: 0`
  - 滑入动画：`transform: translateX(100%)` → `translateX(0)`，`transition: transform 0.25s ease`
  - 阴影：`box-shadow: -4px 0 24px rgba(0,0,0,0.18)`
  - 点击外部区域关闭抽屉
  - 保留现有 `RoomDetailPane` 作为路由驱动模式的备选
- **验收**：单击卡片 → 抽屉从右侧滑出；点击外部/关闭按钮 → 抽屉滑出关闭

#### P1-2：详情抽屉 Hero + 统计卡片

- **现状**：`RoomDetailPane` 使用 label-value 行展示信息
- **目标**：Hero 区域（大头像 + 名称 + ID）+ 3 列统计卡片（总成员/在线/公告）
- **涉及文件**：
  - 修改：`src/components/room/RoomDetailDrawer.vue`
- **实施要点**：
  - Hero：头像 64x64 圆角矩形 + 名称（16px bold）+ ID（11px 等宽，可复制）
  - 统计卡片行：`grid-template-columns: repeat(3, 1fr); gap: 8px`
  - 每张卡片：数字（18px bold，强调色）+ 标签（10px，弱化色）
  - 公告数从 `roomStore` 或 pinned messages 获取
- **验收**：Hero 区域布局正确；统计卡片数字准确

#### P1-3：最近消息 + 核心成员

- **现状**：无
- **目标**：显示最近一条消息预览 + 核心成员列表
- **涉及文件**：
  - 修改：`src/components/room/RoomDetailDrawer.vue`
  - 数据源：`chatStore` 最后消息 + `groupStore.getMembersByRoomId`
- **实施要点**：
  - 最近消息：发送者头像 + 名称 + 内容截断（单行）
  - 核心成员：取前 4-6 个成员（优先管理员/创建者），显示头像 + 名称 + 角色标签 + 在线状态
  - 在线状态点：`--tjg-status-online` / `--tjg-status-offline`
- **验收**：最近消息显示正确；核心成员列表含角色和在线状态

#### P1-4：底部操作栏

- **现状**：垂直排列 3 个按钮
- **目标**：底部固定栏，「进入房间」+「房间设置」并排
- **涉及文件**：
  - 修改：`src/components/room/RoomDetailDrawer.vue`
- **实施要点**：
  - 「进入房间」：主色按钮，flex:1，点击后跳转聊天并关闭抽屉
  - 「房间设置」：次要按钮，flex:1，点击后替换为设置抽屉
  - 底部栏固定：`position: sticky; bottom: 0` 或 flex 布局 `margin-top: auto`
- **验收**：两个按钮并排；点击行为正确

  - Tab 切换：`v-show` 控制各面板显示
  - 从详情抽屉点击「房间设置」→ 关闭详情抽屉 → 打开设置抽屉

#### P2-2：基本信息 Tab

#### P2-3：成员管理 Tab

#### P2-5：其余 Tab（通知/别名/历史/保留/标签/粘性）

- **现状**：全部缺失
- **目标**：各 Tab 基础面板
- **涉及文件**：
  - 新建：`src/components/room/settings/NotificationsTab.vue`
  - 新建：`src/components/room/settings/AliasesTab.vue`
  - 新建：`src/components/room/settings/HistoryTab.vue`
  - 新建：`src/components/room/settings/RetentionTab.vue`
  - 新建：`src/components/room/settings/TagsTab.vue`

## 4. 设计规范对齐

### 4.1 Token 使用

所有新增/修改组件必须使用 `--tjg-*` token，禁止硬编码颜色：

| 用途 | Token |
|------|-------|
| 卡片背景 | `--tjg-surface-raised` |
| 卡片 hover | `--tjg-surface-list-hover` |
| 抽屉背景 | `--tjg-surface-panel` |
| 主文字 | `--tjg-text-primary` |
| 次要文字 | `--tjg-text-secondary` |
| 弱化文字 | `--tjg-text-tertiary` |
| 品牌色 | `--tjg-color-primary-500` |
| 边框 | `--tjg-border-default` |
| 在线状态 | `--tjg-status-online` |
| 离线状态 | `--tjg-status-offline` |
| 危险色 | `--tjg-color-danger-500` |

### 4.2 图标规范

- 必须使用 SVG `<use href="#icon-name">` 或 Iconify
- 线宽 1.5px
- 尺寸：操作图标 16x16，头像内图标 24x24

### 4.3 动效规范

- 抽屉滑入：`transition: transform 0.25s cubic-bezier(0.4, 0, 0.2, 1)`
- 卡片 hover：`transition: all 0.2s ease`
- 尊重 `prefers-reduced-motion`：禁用所有动画

### 4.4 圆角规范

- 卡片：`12px`（`--tjg-radius-lg`）
- 按钮/标签：`8px`（`--tjg-radius-md`）
- 头像：`8px`（房间）/ `50%`（成员）
- 抽屉：左上圆角 `12px`
