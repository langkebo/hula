# UI Alignment Performance Report 2026-05-04

## 本次迭代范围

本轮改动以“审计 + 工程收口”为主，没有引入大规模运行时逻辑重构，因此本报告主要记录基线状态与后续专项性能项，而非宣称已有显著性能提升。

## 本次变更对性能的影响

### 直接影响

- `AddFriendRequestDialog.vue` / `AddGroupRequestDialog.vue`
  - 影响类型：状态接入修复
  - 预期影响：避免错误状态访问导致的额外异常分支，不构成可感知性能提升
- `layout/left/config.tsx` / `Tray.vue`
  - 影响类型：无效引用清理
  - 预期影响：仅降低维护噪音，无显著运行时收益
- 好友接受 -> DM 跳转链路
  - 影响类型：主链路确定性修复
  - 预期影响：移除 `uid + 延迟推断` 的不稳定路径，降低等待同步期间的错误跳转概率
- 房间摘要无权限态
  - 影响类型：降级分支收口
  - 预期影响：在 `membership !== join` 时直接进入无权限态，避免继续触发群详情、成员、公告等无效加载与误导性交互

### 结论

- 本轮不存在显著的渲染性能提升
- 本轮对“好友接受 -> 打开 DM”链路做了确定性优化，为后续做前后对比采样创造了稳定条件
- 本轮对“房间摘要无权限”路径做了短路处理，为后续量化详情侧栏无效请求削减提供了稳定前提

## 当前性能缺口

### P0

1. 房间列表增量 patch 与重连横幅未形成统一基线
2. 大列表变更是否触发整表重绘尚未量化
3. 接受好友请求到进入 DM 的耗时仍缺少量化基线，但链路已从猜测式跳转改为确定性跳转

### P1

1. 空间树 `next_batch` 分页追加的性能表现未量化
2. 好友页分组切换与搜索的主线程成本未量化
