# UI Alignment Acceptance Checklist 2026-05-16

## 使用说明

- 本清单用于发布前 UI 验收。
- 每次涉及好友域、空间域、房间列表、详情区或输入区的改动，都应至少复核一次。
- 若某项依赖实机环境，请在备注中写明执行平台。

## 1. 工作台与空间域

- [ ] 房间工作台在 `wide / compact / narrow` 三种布局下均可正常使用
- [ ] 选中空间后，左栏树导航会出现且可展开子节点
- [ ] `load more` 采用追加加载，不会重置已展开的树路径
- [ ] breadcrumb 点击回跳后，树节点、左栏空间和中栏列表保持一致
- [ ] 空间卡片能表达公开 / 私有 / 邀请制 / 受限等状态

## 2. 房间列表与输入态

- [ ] 房间列表可区分 `initial-loading / reconnecting / empty / filtered-empty`
- [ ] 邀请态、已迁移态、无权限态在列表中表达清晰
- [ ] 只读房间不会暴露误导性的可编辑输入框
- [ ] 输入禁用时有明确解释文案，不只是单纯按钮不可用
- [ ] 详情区状态与输入区状态一致，不出现一边可发一边不可发

## 3. 消息区与详情区

- [ ] 消息元信息可展示发送状态、presence、回执和 typing
- [ ] 消息失败时可见重试入口，发送中状态可见
- [ ] 右侧详情区 `summary / members / activity / manage` 四模式切换正常
- [ ] 公告、邀请、加房间和设置动作仍在详情承载域内完成

## 4. 好友域

- [ ] 好友列表四态切换稳定：正常 / 空态 / 异常 / 能力关闭
- [ ] 好友请求接受后可进入正确的 DM
- [ ] 好友详情抽屉与列表之间的切换不会丢失上下文
- [ ] 加好友、搜索、请求处理的结果提示与 live region 播报一致

## 5. 文档与资产

- [ ] 相关 Storybook 入口已补齐并可打开
- [ ] 回归矩阵已回填到 `UI_ALIGNMENT_REGRESSION_MATRIX_2026-05-16.md`
- [ ] 资产索引已更新到 `UI_ALIGNMENT_ASSET_INDEX_2026-05-16.md`
- [ ] 开放任务总表已同步最新 `StorybookTarget / 回归资产 / 完成进度`

## 6. 实机补充

- [ ] 桌面端右键 / hover / focus 行为符合预期
- [ ] 移动端 touch target 与面板切换符合预期
- [ ] RTL / 小屏 / 触屏环境已至少抽样验证一次
- [ ] 若本轮未做实机验证，需在 PR 或发布说明中明确标注
