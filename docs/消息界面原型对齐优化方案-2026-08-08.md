## 〇.1 通话按钮不显示 — 根因分析（P0 Critical）

### 现象
实际截图中聊天头部**完全没有**语音/视频/群通话/按钮，仅右侧显示一个 "+" 按钮。

### 根因：`public/icon.js` 缺少 SVG Symbol 定义

`ChatHeaderToolbar.vue` 使用 SVG Sprite 方式引用图标：

```html
<svg><use href="#video"></use></svg>       <!-- 视频通话 -->
<svg><use href="#phone"></use></svg>       <!-- 语音通话 -->

<svg><use href="#expand"></use></svg>      <!-- 新窗口 -->
<svg><use href="#qr-code"></use></svg>     <!-- 二维码 -->
```

经核实 `public/icon.js`（273KB，184 个 symbol），**以上 5 个 symbol ID 全部不存在**：

| 引用的 symbol ID | 是否存在于 icon.js | 后果 |
|---|---|---|
| `#video` | ❌ 不存在 | 视频按钮渲染但图标空白 |
| `#phone` | ❌ 不存在 | 语音按钮渲染但图标空白 |
| `#screen-share` | ❌ 不存在 | 屏幕共享按钮渲染但图标空白 |
| `#expand` | ❌ 不存在 | 新窗口按钮渲染但图标空白 |
| `#qr-code` | ❌ 不存在 | 二维码按钮渲染但图标空白 |
| `#menu` | ✅ 存在 | 更多按钮正常显示 |

**按钮本身被渲染了**（`<n-button>` DOM 节点存在），但因为 `<use href="#xxx">` 引用了不存在的 symbol，SVG 渲染为空白，用户看到的是**无图标的空按钮**，视觉上等同于"按钮不存在"。

### 次要根因：i18n key 路径不匹配

`ChatHeaderToolbar.vue` 中 tooltip 使用的 i18n key 与实际定义不一致：

| 组件中使用的 key | 实际 i18n 定义路径 | 状态 |
|---|---|---|
| `t('chat.header.video_call')` | `chat_header.toolbar.video_call` | ❌ 路径不匹配 |
| `t('chat.header.voice_call')` | `chat_header.toolbar.audio_call` | ❌ 路径不匹配 + key 名不同 |
| `t('chat.header.screen_share')` | `chat_header.toolbar.screen_share` | ❌ 路径不匹配 |
| `t('chat.header.start_meeting')` | `chat_header.start_meeting` | ❌ 路径不匹配 |
| `t('chat.header.more_options')` | 无对应定义 | ❌ 缺失 |

### 第三根因：`ChatHeaderInfo` 成员数 i18n key 缺失

`ChatHeaderInfo.vue:29` 使用 `t('home.chat_header.member_count', { count })`，但 i18n 定义中：
- `chat_header` 下无 `member_count` key
- 实际成员数 key 位于 `chat_sidebar.members.count: "{count} 位成员"`

导致页面直接显示原始 key 字符串 `home.chat_header.member_count`。

### 修复方案

1. **在 `public/icon.js` 中补充缺失的 SVG symbol**（`#video`、`#phone`、`#screen-share`、`#expand`、`#qr-code`），或改用 `@iconify/vue` 的 `<Icon icon="mdi:video" />` 方式（项目已有 70 文件使用 Iconify）
2. **修正 `ChatHeaderToolbar.vue` 的 i18n key 路径**，与 `i18n.d.ts` 中 `chat_header.toolbar.*` 对齐
3. **在 `chat_header` 下新增 `member_count` i18n key**，或修改 `ChatHeaderInfo.vue` 使用已有 key `chat_sidebar.members.count`
