## 🔴 P0 - 阻塞性问题（立即执行）

### 1. UI 系统多源真相分裂

**问题描述**：
- 颜色来源分散：`variable.scss`、`simple.scss`、`default.scss`、`design-tokens.css`、组件内硬编码
- 全仓约 988 处硬编码色值，涉及 200+ 文件
- 主题切换、品牌升级需要逐页返工

**解决方案**：
```
阶段 1：建立权威 Token 中心（3 天）
├── 完善 design-tokens.css 为唯一 Token 注册中心
├── 统一使用 --hula-* 前缀命名
└── 定义完整的 core/semantic/component tokens

阶段 2：清理遗留变量（4 天）
├── 删除 default.scss（已确认未被运行时导入）
├── 清理 variable.scss 中的无消费变量
├── 迁移剩余的 --line-color、--chat-text-color 消费点
└── 禁止新增无前缀变量

阶段 3：组件迁移（持续）
├── 优先迁移高频组件（已完成 50+ 个）
├── 建立 Token 使用规范文档
└── 在 CI 中添加硬编码色值检查
```

**验收标准**：

   - 风险：类型检查失败，影响开发效率
