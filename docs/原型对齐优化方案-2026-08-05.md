# TJG 原型对齐优化方案 — 系统性差异审查与实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> 审查日期：2026-08-05 · 方法：writing-plans（Superpowers）
> 审查基线：`docs/TJG-prototype.html`（18081 行高保真原型，暗色主题）
> 约束文档：`docs/icon-strategy-evaluation.md`（图标策略）、`docs/重构优化方案.md`（全局约束）

**Goal:** 使项目界面在视觉呈现、交互逻辑、组件排布、用户体验四个维度准确还原 TJG-prototype.html 原型设计，同时遵循 icon-strategy-evaluation.md 确定的「Sprite 存量保留 / Iconify 增量首选 / 内联 SVG 收敛」图标策略。

**Architecture:** 以 design-tokens.css 的 `--tjg-*` token 为唯一色彩/字体/动效来源，通过 token 值修正（不改架构）+ 组件级样式收敛 + aria 属性补齐三条路径实施；所有改动不改变现有交互行为与 Matrix 服务层调用链。

**Tech Stack:** Vue 3 + TypeScript + UnoCSS + SCSS + Naive UI + Vitest + axe-core

## Global Constraints

- 不得引入新依赖（axe-core@4.12.1 已存在）。
- 不得改变现有交互行为（拖拽、视图切换、响应式断点、消息收发）。
- Matrix 操作必须走 `src/services/matrix/` 服务层，禁止组件直连 SDK。
- 图标必须 SVG；禁止 div-based 图标。
- 图标策略：Sprite（`public/icon.js`）存量 156 文件不迁移；Iconify 增量首选；内联 SVG 按 `src/views/admin/icons/` 样板收敛。
- 原型为**暗色主题单主题**设计；对齐目标为 `html[data-theme='dark']` 下的视觉还原，浅色主题仅修正对比度违规项。
- 验收基线：`vue-tsc --noEmit` 0 errors + `vitest run` 全绿 + `biome check` clean。
- commitlint scope 限定：core/ui/chat/mobile/plugin/hook/service/util/i18n/config/ci/test/tauri。
