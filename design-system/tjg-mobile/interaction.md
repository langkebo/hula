# TJG Mobile · 交互与动效说明

> 配套 [MASTER.md](./MASTER.md) 与 [components.md](./components.md)。
> 目标：把液态玻璃的“材质感”落到触控、手势、动效节奏与信息层级上，而不是只换一层半透明背景。

## 1. 触控基线

| 规则 | 说明 |
| :--- | :--- |
| 热区 ≥ 44×44px | 图标按钮用透明扩展区补足；列表行 ≥ 56px |
| 即时反馈 ≤ 100ms | 按下必须在首帧给出背景/透明度变化，不等抬手 |
| 单次点击只做一件事 | 长按与点击不共享同一区域语义；长按 500ms 触发 |
| 双击保护 | 发送、支付、删除等不可逆操作 600ms 内去重 |
| 触控目标间距 ≥ 8px | 相邻图标按钮之间不得紧贴 |
| `touch-action: manipulation` | 所有可点击元素，避免 300ms 点击延迟 |
| `-webkit-tap-highlight-color: transparent` | 统一关闭系统高亮，改由 `:active` 表达 |

### 按下态规范

| 元素 | 反馈 |
| :--- | :--- |
| 列表行 | 背景 → `--tjg-glass-row-bg-pressed`，120ms |
| 独立卡片 / 九宫格 | 背景 + `scale(--tjg-glass-press-scale)`，120ms |
| 图标按钮 | 透明度 0.6，120ms |
| 主按钮 | 亮度 0.94 + 内高光增强 |
| 标签栏项 | 图标 0.96 缩放，120ms |

禁止：`opacity: 0` 到 `1` 的整体闪烁；按下位移导致相邻元素重排。

## 2. 手势

| 手势 | 场景 | 行为 |
| :--- | :--- | :--- |
| 左滑 | 会话行 / 消息 | 露出操作区（置顶、删除、回复），最大位移 160px，超出回弹 |
| 长按 500ms | 会话行 / 消息 | 玻璃菜单浮出，锚点跟随触点，自动避让屏幕边缘 12px |
| 下拉 | 会话列表 / 聊天记录 | 刷新，阻尼 0.5，超过 64px 触发 |
| 上滑 | 聊天记录 | 加载更多，距顶 120px 预取 |
| 上滑取消 | 录音 | 位移 > 60px 进入取消态，松手放弃 |
| 边缘右滑 | 二级页面 | 返回，跟手位移 + 底层页面 0.96 缩放 |
| 双击 | 消息 | 快捷回应，气泡上方浮出 6 个反应图标 |

手势必须同时提供可点击替代路径（例如左滑删除也出现在长按菜单中）。

## 3. 动效节奏

| 场景 | 时长 | 曲线 | 说明 |
| :--- | :--- | :--- | :--- |
| 按下反馈 | 120ms | `--tjg-motion-ease-standard` | 只改颜色/透明度 |
| 松开回弹 | 180ms | `--tjg-motion-ease-standard` | 回到静止态 |
| 面板/抽屉进入 | 320ms | `--tjg-motion-ease-enter` | `translateY(24px)` + 淡入 |
| 面板/抽屉退出 | 240ms | `--tjg-motion-ease-exit` | 反向，禁止延迟 |
| 页面推入 | 420ms | `--tjg-motion-ease-standard` | 新页右入 24px + 淡入，旧页 0.98 |
| 页面返回 | 320ms | `--tjg-motion-ease-exit` | 反向 |
| 键盘联动 | 180ms | 线性 | 输入坞跟随 `visualViewport` |
| 列表项首现 | 240ms，逐项 +20ms | 标准 | `opacity` + 上移 4px，最多 8 项递进 |
| 未读徽标变化 | 200ms | 标准 | 数字滚动或淡入，不做弹跳 |
| 骨架屏 | 1.4s 循环 | 线性 | 仅 `background-position` 位移 |

禁止：>500ms 的常规动效；`height/width/top/left` 过渡；列表滚动中触发缩放动画。

## 4. 信息层级

1. **一屏一主任务**：会话列表 = 找会话；聊天页 = 读与发；功能面板 = 选能力。
2. **三级文字**：标题 15–17px / 正文 15px / 辅助 11–13px。同级不得混用两种字号。
3. **色彩克制**：一屏只有品牌色（选中/发送）与状态色（未读/在线）两处高饱和。
4. **玻璃层级与信息层级一致**：越靠前的内容用越亮的玻璃，弹层永远比背景亮。
5. **空态**：图标 + 一句说明 + 一个主操作，垂直居中偏上 12vh。
6. **加载**：<300ms 不显示 loading；>300ms 用骨架屏；>5s 出现重试入口。

## 5. 键盘与输入

- 输入坞使用 `visualViewport.resize` 计算位移，避免 iOS 键盘遮挡。
- 键盘弹起时聊天列表滚动到底部（仅当原本在底部）。
- 面板与键盘互斥：打开键盘关闭功能面板，反之亦然。
- 输入框获得焦点后，导航栏不位移，仅输入坞上移。
- 录音 / 面板 / 表情三个入口点击后保持输入框焦点状态可见。

## 6. 无障碍

- 所有图标按钮提供 `aria-label`；装饰性玻璃层 `pointer-events: none`。
- 焦点态：2px 品牌色描边 + 2px 偏移，不被玻璃背景吞掉。
- 动效、透明度、模糊三者都要有降级（见 MASTER 第 8 节）。
- 文字对比度 ≥ 4.5:1；浅色玻璃上的白字必须改为深色或加深底色。
- 状态不以颜色单独表达：未读同时有数字，在线同时有圆点形状差异。

## 7. 响应式行为

| 断点 | 行为 |
| :--- | :--- |
| ≤360px | 横向留白 12px；九宫格 gap 10px；气泡最大宽 82vw |
| 361–430px | 基准 |
| ≥431px | 内容居中，最大宽 560px；气泡最大宽 68vw |
| 横屏 | 标签栏不显示（改为侧边或隐藏）；输入坞保持底部；面板最高 60vh |
| 平板 / 折叠屏 | 会话列表与聊天双栏；玻璃面贴合各自安全区 |

## 8. 性能预算

| 指标 | 目标 |
| :--- | :--- |
| 首屏列表滚动 | 稳定 60fps，长列表无逐行模糊 |
| 同屏模糊元素 | ≤ 4 |
| 动画期间布局抖动 | 0（只用 transform / opacity / filter） |
| 输入响应 | 键盘弹起后 1 帧内输入坞到位 |
| 面板打开 | ≤ 320ms 完成，动画期间不重新计算列表 |

## 9. 验收脚本（手工）

1. 360 / 390 / 430 三档宽度：无横向滚动、无文字截断、九宫格不换行错位。
2. 深/浅色主题：玻璃面上的所有文字均可读；切换主题无闪烁。
3. 开启「降低透明度」与「减少动态效果」：界面退化为实色但层级仍清晰，无动画。
4. 键盘弹起 / 收起：输入坞跟随，聊天列表不跳动。
5. 长按会话行：菜单贴合触点，靠近边缘自动翻转，点击空白关闭。
6. 左滑会话行：操作区完整露出，纵向滚动不误触。
7. 面板 → 键盘 → 面板：互斥正确，无重叠。
