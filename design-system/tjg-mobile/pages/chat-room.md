# 页面覆盖 · 聊天页（/mobile/chat-room）

> 覆盖 [MASTER.md](../MASTER.md)。实现：[MobileChatMain.vue](../../../src/mobile/views/chat-room/MobileChatMain.vue)、[HeaderBar.vue](../../../src/mobile/components/chat-room/HeaderBar.vue)、[FooterBar.vue](../../../src/mobile/components/chat-room/FooterBar.vue)

## 布局结构（四层）

1. **氛围层**：无自定义会话背景时使用 `.tjg-aurora`；有背景图时图片上压 10% `--tjg-glass-scrim`。
2. **导航栏**：`.tjg-glass--nav`，44px + 顶部安全区；左返回、中标题、右更多，标题下 11px 在线状态/成员数。
3. **消息流**：上下内边距 12px，左右 12px；气泡组间距 16px，组内 4px。顶部下拉出现“加载更多”玻璃胶囊。
4. **输入坞**：`.tjg-glass--input` + 底部安全区；上方与消息流之间留 8px 透明间隙，让玻璃边缘可见。

## 视觉要点

- **接收气泡**：`--tjg-glass-tint-bubble-received` + 10px 模糊 + 内高光，文字主色。
- **发送气泡**：`--tjg-glass-tint-bubble-sent` + 顶部 `--tjg-glass-sheen`，白字；其白字对比度靠 86% 品牌绿保证，禁止再降低不透明度。
- 头像 36px（聊天流）与气泡间距 8px；连续消息只首条显示头像。
- 时间分隔：居中胶囊，11px，`--tjg-glass-row-bg` 底，间距上下 12px。
- 系统消息（入群、撤回）：居中 12px 文字，`--tjg-text-tertiary`，无气泡。
- 图片/视频卡片：最大宽 60vw、圆角 `--tjg-radius-lg`、1px 玻璃描边；加载中用骨架屏。
- 语音条：高 44px，最小宽 120px，按 1 秒 ≈ 3px 增长，上限 60vw；播放中波形使用品牌色。

## 输入区细节

| 状态 | 表现 |
| :--- | :--- |
| 空闲 | 左侧扩展钮 36px、输入框 36px、右侧表情/发送 |
| 聚焦 | 输入框描边 → `--tjg-glass-border-strong`，发送键由灰转品牌色 |
| 有内容 | 发送键启用，按压缩放 0.96 |
| 录音 | 输入框替换为“松开发送 / 上滑取消”，面板关闭 |
| 多行 | 最高 120px，内部滚动，输入坞整体上移，圆角保持 full |

键盘处理：监听 `visualViewport.resize`，输入坞 `translateY` 跟随，180ms 线性；列表仅在原本贴底时滚到底。

## 交互

| 操作 | 表现 |
| :--- | :--- |
| 单击气泡 | 无变化；双击弹出快捷回应 |
| 长按气泡 | 玻璃菜单（复制/回复/转发/撤回/多选），锚点避让 12px |
| 点击空白 | 关闭面板与菜单，键盘保留 |
| 上滑列表 | 加载更早消息，距顶 120px 预取 |
| 下拉 | 刷新当前会话，阻尼 0.5 |
| 返回 | 边缘右滑跟手，320ms 完成 |

## 响应式

- ≤360px：气泡最大宽 82vw，导航标题最多 12 字，超出省略。
- 横屏：输入坞贴底，面板高度上限 60vh，导航栏不增高。
- ≥431px：消息流最大宽 560px 居中，气泡最大宽 68vw。

## 验收

- [ ] 深浅色下发送/接收气泡文字均 ≥ 4.5:1
- [ ] 键盘弹起/收起输入坞无跳变，消息流不闪
- [ ] 长按菜单不出屏，点击遮罩可关闭
- [ ] 面板、键盘、录音三者互斥
- [ ] “降低透明度”开启后气泡退为实色仍可读
