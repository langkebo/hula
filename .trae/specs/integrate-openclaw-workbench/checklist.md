# 验收清单

- [x] 当前 chatbot/robot 对应的桌面入口已统一为 OpenClaw 工作台入口
- [x] 桌面端不再保留与 OpenClaw 平行存在且能力重复的旧 chatbot 默认主界面
- [x] OpenClaw 工作台 UI 已参考 `openclaw-UI--Chinese` 的布局语义，并与 HuLa 现有主题风格保持一致
- [x] 工作台包含欢迎态、消息区、输入区、连接状态区和关键操作入口
- [x] OpenClaw 可连接时，界面能正确展示连接状态、可用模型和流式响应结果
- [x] OpenClaw 不可连接时，界面能展示明确错误信息，并提供重试或检查配置入口
- [x] 空会话、处理中、失败、成功等关键状态在统一工作台中均有稳定反馈
- [x] 系统可检测桌面端当前是否已安装 OpenClaw 模块
- [x] 未安装时，界面可根据 `windows`、`macos`、`linux` 展示对应安装提示
- [x] 界面包含“一键安装 OpenClaw”按钮，且按钮状态会随安装进度变化
- [x] 一键安装成功后，界面会自动刷新安装状态并引导后续连接或启动
- [x] 一键安装失败或不满足前置条件时，界面会保留可执行的手动安装兜底方案
- [x] 当前 chatbot 入口、旧 OpenClaw 入口和统一工作台之间的导航行为一致且无重复跳转
- [x] 与本次修改相关的类型检查、关键界面回归和必要测试已完成
