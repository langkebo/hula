### 2.1 Details 组件（右侧栏详情）

**文件**: `src/components/rightBox/Details.vue`
**测试文件**: `src/components/rightBox/__tests__/Details.test.ts`

| 用例 | 验证点 | 结果 |
|------|--------|------|
| 展示选中好友的头像、昵称、账号和四个操作按钮 | 渲染 `singleName`、`singleUid`、`singleAccount`；`.single-details__action` 数量为 4 | ✅ 通过 |
| 点击发消息按钮会打开会话 | `openMsgSession` 被调用；`startDirectRoom` 被调用（加密聊天）；`startRtcCall` 调用 2 次（语音+视频） | ✅ 通过 |
| 缺少好友信息时使用统一反馈提示 | `showFeedback` 以 `warning` 类型提示；`openMsgSession` 未被调用 | ✅ 通过 |
| 展示好友管理区域并支持设置备注 | `.single-details__management` 存在；点击修改备注按钮后 `.management-edit` 出现 | ✅ 通过 |

**操作按钮清单**（SINGLE 类型）:
1. 发消息 → `openMsgSession(uid, SINGLE)`
2. 加密聊天 → `contactStore.startDirectRoom(uid, true)` + `openMsgSessionByRoomId`
3. 语音通话 → `openMsgSession` + `startRtcCall(AUDIO)`
4. 视频通话 → `openMsgSession` + `startRtcCall(VIDEO)`

**管理功能清单**:
- 备注编辑（`contactStore.setFriendNote`）
- 显示名编辑（`contactStore.setFriendDisplayName`）
- 好友状态管理：收藏 / 普通 / 屏蔽（`contactStore.setFriendStatus`）
- 删除好友（`contactStore.removeFromContacts` + 确认对话框）

**GROUP 类型操作按钮**:
1. 发消息 → `openMsgSession(uid, GROUP)`
2. 视频通话 → `openMsgSession` + `startRtcCall(VIDEO)`

## 3. 交互流程验证

### 3.1 好友列表 → 详情 → 发消息

```
用户点击好友列表项
  ↓
FriendListView.handleSelectFriend(friend)
  ↓ useMitt.emit(DETAILS_SHOW, { context: { type: SINGLE, uid }, detailsShow: true })
right/index.vue 接收事件
  ↓ detailsContent.value = event.context; detailsShow.value = true
Details.vue 渲染好友详情（头像、昵称、状态标签、操作按钮、管理区域）
  ↓ 用户点击"发消息"按钮
Details.handleSendMessage()
  ↓ openMsgSession(uid, SINGLE)
跳转至 /message 路由，打开聊天界面
```

### 3.2 房间列表 → 详情 → 发消息

```
用户单击房间列表项
  ↓
RoomList.handleRoomSelect(item)
  ↓ useMitt.emit(DETAILS_SHOW, { context: { type: GROUP, uid: roomId }, detailsShow: true })
right/index.vue 接收事件（isDetails 现在覆盖 /roomList 路由）
  ↓
Details.vue 渲染房间详情（群头像、群名、操作按钮、公告、成员列表）
  ↓ 用户点击"发消息"按钮
Details.handleSendMessage()
  ↓ openMsgSession(uid, GROUP)
跳转至 /message 路由，打开群聊界面
```

### 3.3 好友详情 → 加密聊天

```
用户在好友详情页点击"加密聊天"按钮
  ↓
Details.handleEncryptedChat()
  ↓ contactStore.startDirectRoom(uid, true)  // encrypted = true
  ↓ openMsgSessionByRoomId(roomId)
跳转至加密聊天界面
```

### 3.4 好友详情 → 视频通话

```
用户在好友详情页点击"视频通话"按钮
  ↓
Details.handleVideoCall()
  ↓ ensureSessionReady() → openMsgSession(uid, SINGLE)
  ↓ startRtcCall(CallTypeEnum.VIDEO)
Tauri 创建独立 rtcCall 窗口
```
