# 2026-09-19 UI/UX 审计诊断

## 任务
作为 UI/UX 设计系统总监，对 Tjg/HuLa IM 项目进行全面的 UI 审计，诊断问题并提供美化建议。

## 审计范围
- 设计令牌体系（design-tokens.css）
- 样式架构（SCSS/CSS）
- 核心视图组件（login, home, settings, admin）
- 布局系统（left/center/right）
- 无障碍支持
- 响应式设计

## 关键发现

### 🔴 P1 问题
1. **Token 命名混乱**：代码中存在 --tjg-*, --hula-*, --color-*, --bg-* 多种前缀，backward-compatible aliases 未清理
2. **内联样式泛滥**：核心视图发现 73 处内联 style 属性，破坏设计一致性

### 🟡 P2 问题
3. **!important 滥用**：48 处使用，主要是覆盖 Naive UI 默认样式
4. **管理后台脱节**：admin 模块使用硬编码颜色值，缺少暗色主题支持
5. **字体加载策略**：字体文件位置错误，缺少多字重变体

### 🟢 P3 问题
6. **无障碍细节**：部分 SVG 图标缺少 aria-hidden 描述
7. **响应式断点**：设计文档与实际代码不一致

## 改进建议
- 清理 backward-compatible aliases，统一使用 --tjg-* 命名空间
- 迁移内联样式到 scoped CSS/SCSS
- 使用 Naive UI theme-overrides 替代 !important
- 管理后台 token 化改造
- 字体文件移至 public/fonts/
