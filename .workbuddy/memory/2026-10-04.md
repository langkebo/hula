## i18n 命名空间重复清理（提交 f5c775d4）

发现 `check-i18n-dead-keys` 报 690 孤儿键（基线 0），根因是**早前 JSON 层并集合并**把
已拆出去的 admin 子树又粘回 `common.json`，以及 thread/widget 重复。

清理内容（-1516 行）：
- `common.json` → 移除 `admin` 子树（676 扁平键，与独立 `admin.json` 命名空间重复）
- `common.json` → 移除 `thread` 子树（与 `thread.json` 重复）
- `common.json` → 移除 7 个无引用 widget 键 + `window_titles.settings` + `loading`
- `admin.json` → 移除无引用 `users.setRateLimit`
- 重新生成 `src/typings/i18n.d.ts`

验证：dead-keys OK 孤儿 0（基线 0）/ refs OK unresolved 0 fallback 0 / biome 202 文件 0 错。

**重要教训**：合并 locale JSON 时，「JSON 层并集」会把**对方已迁走的旧命名空间**重新粘回来。
必须先判定每个子树的**权威归属文件**（本仓是文件名即命名空间），只保留对方真正独有的叶子键，
不能整棵子树照搬。
