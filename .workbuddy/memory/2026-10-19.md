## 🚨 重大教训：本仓**禁止** `git stash push -- src`

为验证"失败是否既有"，我执行 `git stash push -u -- src locales`，
结果把**并行 WIP 的 28 个已追踪文件一起卷走**（PermissionGuard、ChatMain、
settingsSchema、SettingsPage、contacts/list.ts…）。
随后 `git stash pop` **只恢复了 untracked，已追踪改动全部留在 stash**
（且 pop 静默失败、stash 条目仍在）。

恢复方式（验证有效）：
```bash
git checkout stash@{0} -- $(git stash show --name-only stash@{0})   # 只取这些路径
git reset                                                            # 取消暂存
git diff stash@{0} -- src locales   # 应为空，确认完全一致
git stash drop stash@{0}
```
绝不能对整仓 `git checkout stash@{0} -- .`（会把 meta/pnpm-lock/vendor 的并行 WIP 一起回滚）。

**正确做法**：要验证"某失败是否既有"，用
`git worktree add --detach /tmp/head HEAD` + symlink node_modules（记忆里早就写了），
**不要动工作区**。
