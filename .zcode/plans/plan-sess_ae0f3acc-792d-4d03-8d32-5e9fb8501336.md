# 房间卡片美化 + 成员去重加固

## Context

用户要求：
1. 修复消息列表和房间列表中成员重复显示（test1 等成员出现多次）
2. 美化房间列表中的房间卡片，每种房间展示不同的色彩（参考 TJG-prototype.html）
3. 空间和好友的卡片不能在房间列表展示

经排查，三层去重机制已就位（数据层 localpart 去重、store 层 uniqBy+DM 去重、渲染层过滤），但用户仍反馈重复。需加固去重 + 新增防御性 computed 兜底。

房间卡片当前为统一灰白底色（`bg-[--tjg-surface-raised]`），无任何按类型/属性区分的色彩。原型虽未定义 per-type 卡片色，但设计令牌体系已有完整的 primary/success/info/warning 色阶可供映射。

---

## Task 1: 成员去重加固

### 1.1 `allUserInfo` computed — localpart 归一化去重（核心修复）

**文件**: `src/stores/domains/chat/group/members.ts` (line 44-53)

当前 `allUserInfo` 用 `userId === m.userId` 去重。WS 推送的 userId 可能是 localpart（`test1`），SDK 返回完整 MXID（`@test1:matrix.test`），导致同一个人出现两次。

**改动**: 用 `Set<localpart>` 替代 `findIndex`，确保 localpart 和完整 MXID 混合场景下去重正确。

### 1.2 `useSessionListState.ts` — 防御性日志

**文件**: `src/composables/workbench/useSessionListState.ts`

在 `dedupedByRoom` 之后增加 debug 级别日志：如果 `chatOnlySessions.length !== dedupedByRoom.length`，记录警告，便于排查 store 层重复问题。

### 1.3 测试补充

**文件**: `src/stores/domains/chat/group/__tests__/members.test.ts`

补充测试用例：模拟 localpart 和完整 MXID 混合场景，验证 `allUserInfo` 不产生重复。

## Task 2: 房间卡片美化 — 按属性差异化色彩

### 2.1 新增设计令牌

**文件**: `src/styles/css/design-tokens.css`

新增房间卡片类型色 token（基于现有 primary/success/info 色阶）：
- `--tjg-room-card-group-accent`: primary-500（普通群聊左边条）
- `--tjg-room-card-encrypted-accent`: success-500（加密群聊左边条）
- `--tjg-room-card-federated-accent`: info-500（联邦群聊左边条）
- 对应的 border 和 bg token

### 2.2 `RoomCardViewModel` 增加 `roomType` 字段

**文件**: `src/components/room/RoomCardItem.vue`

接口增加 `roomType?: RoomTypeEnum`。

### 2.3 `useRoomCardViewModels` 传递 roomType

**文件**: `src/composables/room/useRoomCardViewModels.ts`

`buildViewModel` 返回对象增加 `roomType: session.type as RoomTypeEnum`。

### 2.4 `RoomCardItem.vue` — 按类型应用差异化样式

**文件**: `src/components/room/RoomCardItem.vue`

- 新增 `computed cardClasses`，根据 `isEncrypted` > `isFederated` > `group` 优先级返回对应 class
- `<article>` 绑定动态 class
- SCSS 增加 modifier：加密→绿色左边条，联邦→蓝色左边条，普通→品牌色左边条
- 边框颜色也随类型变化

### 2.5 测试更新

**文件**: `src/components/room/__tests__/RoomCardItem.test.ts`

- fixture 增加 `roomType`
- 新增加密/联邦房间渲染 class 测试
